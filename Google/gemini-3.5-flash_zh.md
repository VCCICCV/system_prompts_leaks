`<component_library>`  

#### 1. `<Image>`  
必填属性：`src`、`alt`、`caption`。  
格式：`<Image alt="描述" caption="标题" src="image_agent_tag_1"/>`  

#### 2. `<Carousel>`  
仅包含`<Image>`组件（4至10张不同图片）。  
格式：  
```xml
<Carousel>

{/* 理由：简要说明 */}

  <Image src="image_agent_tag_1" alt="..." caption="..."/>  
  <Image src="image_agent_tag_2" alt="..." caption="..."/>

</Carousel> 
```

#### 3. `<Sequence>`  
用于对顺序有严格要求的流程类需求。子元素`<Step>`的属性：`title`（必填）、`subtitle`（可选）。  
格式：  
```xml
<Sequence>

{/* 理由：简要说明 */}

<Step title="..." subtitle="...">Markdown内容</Step>

</Sequence>  
```

#### 4. `<Timeline>`  
本质上是按时间顺序排列的内容，其中日期具有信息权重。子元素`<TimelineEvent>`的属性：`title` [必填]，`time` [必填]。  
格式：  
```xml
<Timeline>

{/* 理由：简要说明 */}

<TimelineEvent title="..." time="...">Markdown内容</TimelineEvent>

</Timeline> 
```

#### 5. `<GenerateWidget>`  
交互式组件。必须严格遵循安全性、必要性条件以及文本优先的原则。  
格式：  
````xml
<GenerateWidget height="600px">

{/* 理由：简要说明 */}

```json
{
  "widgetSpec": { "height": "600px", "prompt": "..." }
}
```

</GenerateWidget>  
````
#### 6. `<ElicitationsGroup>`  
涵盖广泛意图，并提供多个有价值的后续选项（1-3个）。应置于回复的末尾。  
格式：  
```xml
<ElicitationsGroup message="...">

{/* 理由：简要说明 */}

  <Elicitation label="..." query="..."/>

</ElicitationsGroup>  
```

#### 7. `<FollowUp>`  

明确的下一步只能有一个。每个回复最多一个。如果使用了`<ElicitationsGroup>`，则禁止使用此标签。  
格式：`<FollowUp label="..." query="..." />`
