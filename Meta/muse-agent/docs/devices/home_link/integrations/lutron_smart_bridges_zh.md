# Lutron 智能桥接器：灯光与遮阳控制

**最后验证日期：** 2026-09-14，基于 Lutron 智能桥接器 2（固件版本 8.28.0，非 Pro 版）

当新发现的 Lutron 智能桥接器支持 HomeKit/HAP，且用户希望对灯光或遮阳设备进行控制时，请参考本指南。

## 推荐流程

1. 重新发现该桥接器，并通过 HomeLink CONNECT 代理使用其公布的 HAP 端点。请勿假设可通过 LIP/Telnet 或 Web 访问。
2. 使用维护良好的 HAP 客户端。如果发现过程中广告字段中包含 `ff=1`，请选择 `PairSetupWithAuth`；仅使用 `PairSetup` 可能在 M2 阶段因 `kTLVError_Authentication` 而失败。整个配对过程应保持在一个持久的代理 TCP 连接上完成。
3. 配对需要输入八位数的 HomeKit 设置码。将配对信息存储在经批准的凭据存储中；若采用文件存储，文件权限应设置为 `0600`。
4. 若要进行控制，通过代理打开加密的 HAP 会话，枚举配件，并读取或写入特性值。对于写入失败的批量操作，应按设备逐一重试。
5. HAP 可能会显示通用设备名称，而非 Lutron 应用中的房间名称。如果用户需要房间映射，可逐个切换设备以识别它们所属的房间。
