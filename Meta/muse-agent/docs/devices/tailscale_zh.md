# Tailscale

此设备在您的 Tailscale 网络中请求名为 `muse` 的主机名。

Tailscale 是一种私有网络，可将该虚拟机接入用户自己的设备。连接成功后，这些设备可通过 Tailscale 分配的 tailnet 地址访问，地址范围为 `100.64.0.0/10`——即从 `100.64.` 到 `100.127.`，而不仅仅是 `100.64.`。

此设备仅以客户端身份加入：它只发起出站连接，不接受任何入站连接。它无法从 tailnet 中被访问，不托管任何服务，也不为其他设备路由流量。

> Tailscale 支持目前仍处于实验阶段，仍在开发中。

## 连接

```bash
tailscale up
```

该命令会输出一个链接。**请将此链接展示给用户并请他们打开**——只有用户本人才能批准该设备。批准后，加入过程会自动完成；一旦用户批准，连接就会建立，您可以通过 `tailscale status` 来确认连接状态。

在等待期间可以安全地再次运行该命令：它会再次显示相同的链接，并持续监听用户的批准。该链接有效期为五天。每次提示后，设备会在一段时间后停止监听，因此如果用户需要更长时间，请再次运行该命令，它会继续使用同一个链接。

如果用户自建了控制服务器（如 headscale 或其他自托管的控制平面），则需按原生 CLI 的方式传递参数——仅支持 HTTPS 协议的地址：

```bash
tailscale up --login-server https://headscale.example.com
```

这一设置会被持久保存，`tailscale status` 会显示当前使用的登录服务器；若要切换到其他服务器，需先执行 `tailscale down`。使用自定义服务器进行的批准不会留下可重复使用的权限：每次批准都是一次性的，并且与特定的服务器绑定，这与普通的 `tailscale up` 不同，后者可以授予长期有效的访问权限。

`tailscale down` 会断开该虚拟机的连接并清除其 Tailscale 身份，因此重新上线时需要再次获得用户批准——当用户希望该虚拟机不再持有访问权限时，请使用此命令。该命令无法从 Tailscale 管理控制台或用户自建的控制服务器中移除该设备，请告知用户自行在这些平台上删除。

## 访问设备

普通网络访问无法直接到达 tailnet。请复用运行时代理，只需将其端口改为 `3130`：

```bash
tunnel_proxy="${HTTPS_PROXY%:*}:3130"
curl --proxy "$tunnel_proxy" --fail-with-body "http://<tailnet-ip>:<port>/<path>"
```

端口用于选择 Tailscale 通道；地址则是目标地址。这种方式可以承载任何 TCP 服务，而不仅限于 HTTP——只需让客户端指向同一代理即可。

**仅支持通过该代理的 TCP 流量。** 隧道传输的是连接，而非数据包，因此 `ping`、traceroute 以及任何基于 ICMP 或 UDP 的流量都无法到达 tailnet——即使目标机器已启动且可达，这些请求也会失败或挂起。失败的 `ping` 请求并不能说明任何问题，不要将其误认为机器已宕机。验证机器是否可达的唯一方法是通过代理建立 TCP 连接。

- 首次访问某个地址时需要单独批准，Web 权限不会自动继承。一旦批准，所选权限的有效期会覆盖该地址上的其他端口和 TCP 服务，包括 SSH，只要通过该代理访问相同名称或 IP 地址即可。对于同一台机器的不同名称或 IP 地址（短名称、完整的 MagicDNS 名称、IPv4、IPv6），则被视为不同地址，需要单独批准；请始终使用同一地址。
- 任何正在等待批准的请求都会一直等待用户响应。这是预期行为，无需超时重试，也不要将这种等待视为失败。
- 如果此设备尚未加入任何网络，或者目标地址不在 tailnet 的覆盖范围内，请求会直接失败，而不会回退到公网。请检查 `tailscale status`。
- 切勿在命令行中直接包含凭据。

## 查询状态

`tailscale status` 会列出连接状态及所有设备及其地址；`tailscale ip` 则显示本设备的地址。

设备可以通过 Tailnet IP 地址进行寻址，或者在用户的网络启用了 MagicDNS 时，通过其主机名进行寻址。通过端口 `3130` 发起的请求会使用该网络的 DNS 设置，包括搜索域、分段 DNS、基于 HTTPS 的 NextDNS、普通 DNS、DNS-over-TLS，以及可通过 Tailnet 访问的私有 DNS 服务器。如果某个 DNS 服务器不可用，请求可以尝试同一 DNS 路由中配置的其他服务器。当收到阻止或否定响应时，不会切换 DNS 提供商。这些设置适用于通过 Tailscale 代理发起的请求。连接器不提供出口节点的选择功能。
  
`tailscale status` 命令会显示某个地址是否位于网络中。该命令不会执行连通性探测；请通过代理建立 TCP 连接来测试服务的可用性。
  
## 面向用户的话语
  
请说“您的 Tailscale 网络”或直接提及设备名称。除非用户明确要求，否则不要引用原始命令或 `100.64.0.0/10` 范围内的地址。
