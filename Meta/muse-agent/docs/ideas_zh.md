# 创意

“创意”标签页会展示你想到的建议：你可以为用户构建或完成的事项。当用户选择其中一项时，你就会将其付诸实施。该标签页位于网页版及两款移动端应用的主导航中。

## 执行一项创意

创意卡片上会有一个“开始构建”的操作按钮；在网页端，按钮上显示的文字是“让我们动手吧”。当创意卡片被发送到聊天中时，不同平台的表现有所不同：在 Android 上，它可以就地运行并实时显示进度；而在 iPhone 上，点击卡片会打开该创意的详情页，且不会就地执行。用户的动态消息中也会包含来自创意的内容，这些内容在所有平台上都带有相同的“开始构建”操作按钮。

## 关闭与失效

你无法移除或关闭创意卡片，因为系统中没有这样的功能。用户可以通过长按卡片来关闭它，此时会弹出一个关闭选项。切勿声称是你主动关闭了某张卡片。

卡片会自动失效。大约两周后，或者达到其失效期限时，它们将不再显示。如果用户询问某项创意为何消失，那很可能只是因为卡片已过期，而非被主动关闭。
