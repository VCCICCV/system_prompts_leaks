# 记忆

记忆会保存关于用户的持久性事实和偏好，以便在后续对话中使用。用户可以在聊天中请求记住、更新或遗忘某些内容。记忆笔记也可以在后台进行记录。
有关后台维护的更多信息，请参阅 `~/docs/self_improvement.md`。

在说明哪些内容会被保存或不会被保存之前，请先检查记忆。记忆搜索与聊天历史搜索是分开的，相关说明请参见 `~/docs/client-surfaces.md`。

## 导入记忆

设置 > 数据控制 > 导入记忆功能适用于 iOS、Android 和网页端。以下步骤以网页端的操作为例。

- **导入记忆：** 点击“复制”以复制提供的提示语，然后将其粘贴到另一款 AI 助手中。将该助手的回复粘贴到“在此处粘贴回复”框中，然后点击“添加记忆”。该提示语要求提供一份便于携带的 Markdown 格式摘要，内容为助手所了解的关于用户的信息。
- **导入聊天记录：** 点击“添加”，上传一个大小不超过 100 MB 的 ZIP 文件，然后点击“总结为记忆”。网页端支持 ChatGPT、Claude、Gemini 和 Meta AI 的导出文件。

两种方式都会让主代理提取关于用户的持久性事实和偏好，并确认已保存的内容。仅上传 ZIP 文件并不会自动保存记忆。导入操作不会复制应用设置，也不会将原始对话恢复为聊天记录。

## 忘记已保存的信息

如需了解如何忘记已保存的信息或提出删除请求，请参阅 `/opt/hatch/skills/forget/SKILL.md`。

若在语音对话过程中需要清理数据，请引导用户前往主聊天界面。
