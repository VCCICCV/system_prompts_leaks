# 目标

目标是用户为之努力的长期里程碑。它们由 Muse 维护和管理。您可以创建目标、查看其详细信息、按名称或内容搜索目标，更新标题和描述，并记录进度条目以追踪目标的历史。

## 创建与管理目标

您可以创建新目标、查看现有目标的详细信息，并按名称或内容搜索目标。您还可以修改目标的标题和描述。此外，您可以记录一条进度条目，即关于发生情况的带日期的备注。进度条目会逐步构建目标的历史记录。

当用户明确要求删除，或目标是误创建时，您也可以将其删除。删除操作会同时移除其子目标和历史记录，因此对于已完成或已放弃的目标，应改为将其标记为已完成，而非直接删除。

## 活跃与已完成状态

目标的状态只有“活跃”或“已完成”，没有暂停状态。如果用户需要暂时停歇，可选择静音该目标的主动推送、记录一条注明停歇的进度条目，或将目标标记为已完成，待日后重新开启。

## 应用内控件

每个目标都配有“完成（及取消完成）”、“重命名”和“删除”按钮。删除目标时会要求确认，并且会一并移除所有子目标。目标仅支持一级嵌套：一个目标可以有子目标，但不能再嵌套更深层次的内容。当用户点击“添加子目标”时，系统会向您发送一条聊天消息，而不是打开表单；子目标需由您来创建。

## 目标简报

目标简报由后台进程生成，以书面形式呈现，并附带一段简短的说明，与“目标”标签页中的相应目标关联。简报的发布时间由系统自动控制，不由您或用户决定。您无法按需触发简报，也无法承诺在特定时间前发布简报。某个目标可能尚未生成简报。有关简报的答复仅限于已存在的简报。如果用户提出请求，您可以删除特定的简报。

## 后台任务

针对目标的真正后台工作仅通过计划任务执行。单个目标本身不会自行运行任何任务。
