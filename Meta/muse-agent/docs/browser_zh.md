# 浏览器

浏览器是Muse拥有的服务器端浏览器，用于处理所有与浏览器相关的任务。您可以搜索实时网络、打开页面、提取内容，并执行交互式浏览器任务：导航、点击、输入、上传和下载文件。您可以在用户进行其他操作时在后台完成这些工作，并且在普通虚拟机上可以并行运行多个浏览器任务（机密虚拟机会按顺序排队执行）。当您完成一个浏览器任务时，结果会告知您该任务是成功、失败还是被阻塞。


网络搜索和访问公共互联网是免费的。订阅要求和付费内容的限制在浏览器任务运行之前都是未知的。任务结果是判断成功或失败的唯一依据。

## 限制

- 网络策略和站点防护措施（登录、验证码）可能会阻止任务执行
- 验证码或机器人验证会使任务暂停。您不会自行解决验证码问题，且解决验证码本身也不构成一项独立的任务。请先询问用户是否允许您为浏览器任务解决验证码，并严格遵守其答复范围（仅限本次、仅限该站点、每次询问或绝不允许）；如果用户更愿意自行解决，可在提供此功能的应用中接管实时浏览器。
- 会话不会从用户的设备中继承（参见“会话与登录”）
- 下载的内容会保存到您的机器上，而不是手机上（参见“下载”）
- 某些结账流程会暂停等待确认。任务结果决定了是否成功。
- 在任务运行前无法保证取消或其他类似站点操作的结果；如果任务因“被阻塞”而失败，那么真实的原因为站点防护措施。用户拒绝确认会阻止操作；尝试通过其他途径重试并不能替代用户的拒绝。

如果浏览器任务因需要向用户询问某些信息而暂停，它将等待约三个小时。当用户回复后，请继续同一项已暂停的任务；切勿在同一笔购买或登录过程中启动新的任务，因为第二项任务可能会重复执行相同的工作，包括重复购买。

如果浏览器任务到达了结账页面，可以在继续之前等待用户进行一次一键确认。完全无需人工干预的购买或预订流程目前尚不可用。如果出现确认卡片，用户当时的决定即为最终决策。关于购买后续流程（确认卡片、限额、钱包、退款等）的详细说明，请参阅payments-and-purchases.md文档；涉及资金的操作均应遵循该文档。

## 浏览器权限

浏览器在应用中拥有独立的权限设置，位于“设置 > 连接器 > 浏览器”下：访问网站、提交表单或POST请求、下载文件、上传文件以及填充已保存的凭据，每项均可设置为“允许”、“询问”或“拒绝”。网络访问权限有默认设置，其中包括一个可设为“始终询问”的网站默认值，这些设置位于设置中的独立“权限”标签页，而非“连接器”下。代理本身无法更改这些设置。

## 会话与登录

您的浏览器是一个完全独立于用户设备的服务器端浏览器。用户的本地会话和Cookie不会继承到浏览器中。已连接的账户在此场景中也无帮助：用户已登录的连接器（如Google、Spotify等）并不会让您的浏览器自动登录到相应提供商的网站。连接器与浏览器登录是两回事。设备上的登录状态不会传递到浏览器；浏览器登录必须通过浏览器自身的登录流程完成。

当某个网页任务可能需要登录时，浏览器任务会运行并在必要时到达登录页面。如果凭据已保存在安全保险库中，任务可以安全地请求并填写这些凭据，而无需在聊天中暴露它们。只有当任务本身遇到需要登录的情况时才需要用户接管，而无需提前准备。使用已保存的凭据登录仅在浏览器任务的结果显示成功时才有效。如果任务报告需要捕获登录信息，则表示用户尚未为此站点提供已保存的登录凭据。结果为“禁用”、“不可用”或“被拒绝”并不意味着缺少登录信息；请报告发生的情况，并询问用户希望如何继续。已登录的流程无法事先保证；最终的成功与否取决于实际尝试的结果。Passkey 登录无法在浏览器中完成。当站点仅提供 Passkey 选项时，任务将停止，并提示用户需自行登录。

## 无预留、锁定或预订

浏览器无法在用户决策期间保留票价、锁定价格或预留库存。某些站点确实提供预留功能，但这属于站点自身的特性，而非您可控制的部分。替代方案：定期执行的计划价格检查（非即时），或由用户自行激活的站点付费预留选项。价格或库存的预留是站点的功能，而非代理的能力。

## 下载

下载的文件会保存在您的设备上，而不是聊天中，也不会出现在用户的手机上。它们存储在您的工作空间中。在您明确交付之前，用户无法访问这些文件。交付的方式包括：在聊天中共享文件、将其保存到 `workspace/your_files` 目录使其显示在库中，或者当用户需要一个任何人都可打开的链接时，发布一个临时的公开下载链接（参见 `~/docs/files-and-library.md`；该链接会过期，且在机密虚拟机上不可用）。

## 实时浏览器监控

用户是否能够观看实时浏览器或接管操作，取决于客户端的功能。有些界面支持此功能，有些则不支持。实时浏览器控制的可用性因客户端界面而异。如果用户反馈没有浏览器视图，则表示其客户端不支持此功能。在客户端确认之前，网页编辑器或表单暂不支持实时协同操作。

## 购买与退款

退款撤销由商家决定，您无法直接执行；您可以协助用户向商家申请退款。
