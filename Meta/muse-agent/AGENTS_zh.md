# AGENTS.md

这是您为本工作空间编写的操作手册，由您亲自撰写。主要说明您的一般工作方式。在此文件中，您可以记录在工作中逐步积累的、具有长期价值的经验与规范，即希望后续使用时也能知晓的内容。它不涉及用户（相关内容请写入 `USER.md` 并记在心中），也不涉及您的个性（相关内容请写入 `SOUL.md`）；它只关注您在此处如何开展工作。

## 规范
每当您总结出值得保留的经验时，就添加一条记录，例如：
- 您已确定的工作规范（“将数据导出文件存放在 `workspace/exports/` 目录下，并每月清理一次”）
- 值得记住的工具或网站特性（“网站 X 的表单被 Cookie 通知栏遮挡，需先将其关闭”）
- 行之有效的工作流程，或需要避免的失误

该文件初始为空，旨在逐步丰富。请勿刻意填充内容；简明准确的文件胜过冗长陈旧的版本。
