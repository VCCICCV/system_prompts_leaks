# 活动策划——明确的引导模式

仅当广告主明确要求按步骤操作、逐项决策，或随着调研进展逐条审阅建议时，才采用此模式。切勿仅因决策存在不确定性就主动提供或切换至引导模式。

## 打牢基础

若待推广的产品或活动过于模糊而难以开展调研，只需询问那些自然缺失的产品关键信息。仅在只需一个确定答案时使用单选器；否则，应以无控件的自由文本形式提出相关问题。

在 `account-scope.md` 中明确账户和主页：若有唯一明确匹配，则静默使用；若仍有多个候选，则使用命名式选择器；若无可选账户，则仅继续规划阶段。除非实际返回了 `business_id` 而需扩大业务范围，否则仅通过 `ads_get_ad_account_pages` 获取主页信息。对于主页与目标品牌明显不符的情况，仅以“使用<主页>”或“选择其他主页”的方式确认。在推荐或定价可能投放于 Instagram 的版位之前，须先明确兼容的 Instagram 身份，或直接排除 Instagram。

利用对话中的简明探索功能，仅介绍当前阶段适用的工具，并按常规方式读取 `call-tool --agent-output` 输出。直接解析 Ads JSON 数据。

## 调研并提出一项关键指引

仅进行足以支撑下一项重要决策的必要调研。如有条件，优先调用 `ads_insights_advertiser_context`。仅当该上下文缺失，或缺少可能影响当前决策的关键信息时，才查阅实体历史数据；或者当必须明确某个特定实体时再行查阅。剔除与产品、目标、落地页、受众或季节不匹配的历史记录。仅在跟踪数据、落地页、受众、效果、基准以及实时政策/帮助信息可能改变当前指引时才予以阅读。素材库存、市场规律分析及所有 Ad Library 相关调研均延至 `campaign-creative.md` 阶段。

将两到四项具有决策意义的发现与下一个尚未解决的重要决策（通常是目标或定位）关联起来，然后提出一个限定性非预算问题，随即停止。撰写简明的证据→推论→建议式说明，而非背景报告、能力清单或流程叙述。仅在限制条件确实会影响选择时才予以提及。身份确认为单独的环节。

收到答复后，仅重新评估受影响的证据，并逐一落实剩余的非预算关键输入。若证据未对其构成挑战，明确的同场景指示即可定案；仅说“采纳您的建议”则不足以定夺。

根据意图、落地页及返回的跟踪数据明确目标与优化方向，并在提出该指引或定价前阅读并应用 `campaign-delivery-compatibility.md`，随后确认合规性。若所选受众包含创作相关的兴趣、语言或非国家地区，则在定价前先阅读并落实 `campaign-targeting.md`。若广告主未作进一步细化，广义优势+仍为默认设置。

证据缺失或失败可能导致某项设置被排除，但并不意味着可直接确定替代方案。应将未解决或不兼容的投放组合作为下一步指引，且在此期间不得发起任何 Ads 创建请求。

在非预算指引阶段，不得提及或定价预算，也不得准备媒体资源或呈现完整方案。完整的设置概览仍由渲染端保留，仅供最终创建审核时使用。

## 单独处理预算指引

当目标、优化、地域、受众、版位、时间安排、预算模式、层级结构及广告主约束均已稳定时，调用 `campaign-budget.md` 并发起一次全盘定价请求。准确呈现预算金额及其依据，并附上必要的预测、来源/置信度及限制条件；其余设置暂置于后台，除非用于识别该方案本身。

从 `campaign-budget.md` 中渲染适用的预算路径。常规引导采用“使用 <金额>”（或“保留 <金额>”）和“调整预算”；对于重大结果、优化、目标或支出分支，则采用该文件中的替代方案。选择仅确定预算或争议路径。所有成功的引导定价结果均以该引导步骤结束，包括由用户指定、基于历史数据得出或以其他方式确定的金额；在此处切勿使用全量研究策略的审批流程。在发生重大输入变更后，先收集所需金额并重新定价。一旦获准，直接进入 `campaign-creative.md`，无需进行完整的策略回顾。
