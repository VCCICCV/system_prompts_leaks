# 营销活动定向分辨率

仅当营销活动受众包含尚未以 ISO 国家/地区代码或本次对话中返回的规范对象形式呈现的、与创建过程绑定的兴趣、语言或地理位置时，才需阅读本说明。

首先使用所有已确定的候选项调用一次 `ads_targeting_search`。兴趣查询可能来自广告主，也可能来自当前产品、主页及兼容历史证据直接支持的一小部分兴趣。在查询结果返回之前，这些兴趣均为假设；若证据较弱或不匹配，则不会生成查询，且 Advantage+ 仍将保持广泛定向。

如果某次搜索因属于受限主题而被拒绝，则表示该受众完全无法定向。请勿为同一受众群体搜索同义词、更具体的细分术语或相邻的兴趣；应明确告知该选项不可用，并保持受众范围宽泛，或改用广告主可定向的其他选项。

对于地点，请提供其实际名称，并附上语义正确的 `location_type_hint` 和已知的国家/地区代码：城市、城区/行政区、社区、区域、邮政编码、地址/场所，或市场。请勿附加推测的州或地区信息，且仅在确实存在地址/场所级定位要求时才添加半径。务必同时验证返回的名称、类型、国家/地区和所属区域；即使名称相同，位于不同区域的地点也不视为匹配。

仅将返回的 `targeting_results` 映射为兴趣，`location_results` 映射为地理定位，`locale_results` 映射为语言。在预算分配和营销活动指令中，保留每个选定结果的规范键或 ID；同时纳入这些指令所需的显示元数据，由各工具自行构建其特定的定向配置。避免在面向用户的文案中直接暴露原始 ID。仔细审查所有未解析的条目及警告信息。若仍有多个地点合理，则仅当广告主的表述或经验证的商业证据能够明确区分某一地点时方可选择；否则应进一步确认。

对于未解析的确切地点，应保持开放状态——切勿将其默许扩大至国家层级，亦不得在广告组架构要求对象时仅提供地点名称。对于未解析的兴趣或语言，应予以省略，而非声称其已被包含。Advantage+ 可能会扩展建议，但不会移除已选定的地理定位。保存的受众和自定义受众仍由其专属工具管理。
