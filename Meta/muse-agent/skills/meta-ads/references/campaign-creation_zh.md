# Meta 广告 — 完整的广告系列创建

使用此控制器来构建新的广告系列层级结构。向现有层级添加一个子节点属于 `references/writes.md` 中的独立写入操作。

## 仅路由当前阶段

默认为全量调研模式。在能力发现或身份解析之前，务必确保当前请求已充分说明正在投放或测试的内容，以便在无需推测其运作方式的情况下继续推进。否则，只需在一个自然回合中提出与产品或测试范围相关的必要问题。只有通过这一关卡后，才可进一步精简信息收集。身份、由广告主控制的限制条件，以及基于证据的结果、优化目标、受众或预算选择均由 `campaign-planning.md` 负责。仅在明确要求时才使用引导模式；切勿询问应采用何种模式。在模式切换时，应保留已作出的有效决策。

| 当前需求 | 立即阅读 | 阶段完成标志 |
|---|---|---|
| 全面调研的产品简报、身份、研究、投放计划或计划审批 | `campaign-planning.md`；在非金额类定价输入和广告主约束条件稳定后加载 `campaign-budget.md` | 所有投放决策已一并呈现并获采纳。 |
| 显式分步规划或单独的预算指导 | `campaign-guided.md`；仅在需要预算指导时加载 `campaign-budget.md` | 当前的指导问题已得到解答；预算在创意环节之前已被确认。 |
| 创意计划、素材准备或媒体审核 | `campaign-creative.md` | 整体计划已授权相关素材制作，且所有准备好的广告均已通过媒体审核。 |
| 最终审核、暂停创建、初始 Ads Manager 交接或部分恢复 | `campaign-execution.md` | 所有被审核的对象均存在，广告系列已确认处于暂停状态，且已完成交接流程展示。 |
| 选定的创建后发布或编辑操作 | `campaign-handoff.md` | 请求的投放状态或后续操作已完成，或者广告系列仍处于暂停状态。 |
| 账户因不可用而拒绝写入，或广告主将在 Ads Manager 中自行搭建 | `campaign-manual-setup.md`，替代 `campaign-execution.md` 和 `campaign-handoff.md` | 已接受的计划作为设置指南移交。 |

仅加载首个未完成的阶段。若仅为策略层面的需求，当计划获采纳后即停止，除非广告主要求继续。

## 决策与交互契约

始终保留一个 `next_open_decision`。全量调研模式仅可在以下情况下暂停：产品简报、身份、具有约束力的限制条件、广告主自设的阻碍因素、整体计划审批、创意素材来源、媒体审核或最终创建审批。引导模式每次只解决一个关键设置。

对于每一个有限选项，请使用 `muse.create_options`。务必在撰写任何面向广告主的文本之前调用该接口（参见 `SKILL.md` 第19条规则）；在此之前编写的文本将被视为隐藏注释。待其返回后，再撰写最终回复：先写完整上下文及问题，然后在最后一行单独写出返回的 `embed_token`，之后停止输出。点击操作仅提交 `selectedText`；对同一不变选项给出明确的文字回答也视为等效。两者均不得回答其他问题。相关的产品事实可一并以自由形式提问；切勿用“说出这个词”来代替有限选项的确认。

仅在该决策的所有已选读取内容、背景指令、浏览器任务及待办事项均已完成且不再有后续工作时，方可渲染选项。一旦发送了 `embed_token`，就不得留下任何可能在广告主答复前恢复执行的任务。切勿凭空生成、缩写或打印 `<embed_token placeholder>`；若 `muse.create_options` 调用失败，则表示未显示任何选项。

务必先完成实体解析及其他所有工具的调用。将 `muse.create_options` 单独作为最后一个工具调用，切勿并行执行。成功后，使用其精确的 `token` 组成回复，并且不再调用任何其他接口。为此目的，轮询获取的后台结果并不算作最终完成；请等待其自动完成通知后再创建小部件。

这些审批项始终保持独立：- 身份验证不批准研究或预算；
- 策略审批仅接受所显示的交付计划；
- 创意轴的选择不批准完整的创意方案；
- 渠源操作仅授权该准备工作；
- 媒体审批仅接受与未变更计划配套显示的媒体；
- 最终审核仅授权未变更的已暂停层级结构；以及
- 发布是后续的支出决策。

## 能力与研究下单

遵循 `SKILL.md` 中的发现合同：仅命名一次，且仅使用当前阶段的描述符，并在常规调用时添加 `--agent-output`。研究过程中不得获取后续阶段的创建描述符。

对于完整研究，应在发现之前先确定产品简报。然后按顺序解析身份：获取账户描述符，执行 `SKILL.md` 所要求的确切受保护账户命令，选择账户，获取页面描述符，并针对该账户读取 `ads_get_ad_account_pages`。只有在明确此范围后，方可进行后续读取。定向解析应遵循目标和合规性；预算定价则需基于最终受众、地域、投放位置及层级结构。

广告管理器的创建需要：

- `ads_get_ad_accounts` 和 `ads_get_ad_account_pages`；
- 对于尚未规范化的兴趣、地点或语言，需通过 `ads_targeting_search` 进行搜索以用于创建；
- 调用 `ads_create_campaign`、`ads_create_ad_set`、`ads_create_creative` 和 `ads_create_ad`，并在最终审核前确保所有选定输入模式均为最新状态；当前创意阶段读取的创意模式可重复使用；
- 提供这些模式所需的所有身份、目标、格式及来源；
- 以及在最终批准后，为每个新接受的素材调用 `ads_creative_upload_media`。已有广告引用的素材无需上传。

若缺少必要的创建能力，则不得创建部分层级结构，也不得呈现最终创建审核及其审批选项。流程应停留在计划或创意审核阶段，说明无法执行，并仅提供支持的修订方案。

当接受的特定投放位置的静态图片方案不可用时，应在不暴露内部字段名称的前提下，说明支持的单图替代方案，并询问是否进行修订。绝不可擅自降级已接受的方案。

能力本身不授权生成或上传；此类权限由 `campaign-creative.md` 掌控。

## 私有策略账本

账本仅保留在会话状态中——绝不存于 `MEMORY.md`、文件、数据库记录、持久化策略对象或运行时 API 中。独立跟踪以下内容：

- 账户、主页及 Instagram 身份；
- 目标、宗旨、优化方向、投放目标及追踪设置；
- 合规性、地域、受众、投放位置及层级结构；
- 预算金额与节奏、计算依据、成本来源/置信度、预估量、时间安排、规划模式及策略审批；
- 创意方案、素材来源、准备好的媒体及媒体审批；
- 以及最终审批、返回的广告 ID、交接情况及投放状态。

将每项决策分类为“已定”（含数值、依据及来源）、“默认”（安全的默认值及理由）或“待定”（具体决定及可解决者）。仅对广告主明确提供的字段或经成功结果验证的字段予以确认。由支持技能设定的默认值仍视为“默认”，必须展示以供审批，但不作为证据。回答一个问题后，其他相关字段仍保持待定状态；任何执行关键字段若既无已定数值，也无安全可用的默认值，则会阻止策略或最终审批。

失败的研究属于无效证据，而非否定广告主的事实。

仅使依赖项失效：

```text
身份/投放目标
  -> 追踪 + 宗旨
  -> 合规性
  -> 受众 + 结构 + 投放位置
  -> 预算
  -> 策略审批
  -> 创意方案
  -> 准备好的媒体
  -> 最终审批
```保留未受影响的同级节点及上游工作。物料执行偏差将回溯至最早被标记为无效的决策；仅在新输入稳定后才重新定价。
草稿处于暂存状态，而非已创建状态。无论采用何种形式的对话式确认，Sentinel 仍作为原生写入入口；不会有任何小部件、工件、类型化回复或对话状态取代它。
