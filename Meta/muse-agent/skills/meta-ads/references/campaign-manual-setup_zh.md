# 广告主在广告管理平台中完成的广告系列设置

当针对该账户的写入操作因“对此广告账户不可用”而被拒绝时，请阅读本说明——无论是由工具返回（见 `writes.md`），还是广告主引用其先前尝试中的错误信息——或者当广告主希望自行在广告管理平台中设置广告系列时。这一步骤取代了创建流程，而非规划：规划仍由您负责，而具体的点击操作则由广告主完成。

## 解释拒绝原因

这意味着，在该账户被返回时，无法在此处对其进行任何更改。导致这一问题的原因在此处无法直接查看，因此请勿猜测具体原因：企业验证、支付方式、管理员角色以及重新连接等操作均不会改变这一状态，且无论旧版错误提示如何显示，都不存在可供广告主完成的入驻检查清单或步骤。请勿试图寻找此类原因。缺失的支付方式会在广告发布后导致投放无法进行，因此应明确告知这是实际原因，但切勿将其作为拒绝的根本原因。只需说明一次，随后直接进入下一步：完整规划广告系列。切勿提出将计划暂存至访问权限恢复后再执行。

## 完整规划，不进行任何创建

根据您到达此阶段的方式，后续处理有所不同：

- **如果在本次对话中，工具已针对该账户返回账户级拒绝**，则在本次对话的剩余时间内，该账户仅用于规划。请勿再次发送任何写入请求，也无需申请创建审批——此处无法通过审批来创建任何内容。
- **如果广告主引用的是其先前尝试中的拒绝信息**，则该信息并不能证明当前账户的状态：资格可能会发生变化，且可能涉及的是另一个账户。请完整规划，并同时提供设置指南和在此处创建的选项。若广告主选择创建，请遵循 `campaign-execution.md`；首次写入操作要么成功，要么再次返回拒绝，此时将适用上述锁定机制。
- **如果广告主仅选择自行搭建**，则该账户仍可进行写入操作。除非广告主动议，否则请勿为此广告系列发起任何写入；若其改变主意，请返回 `campaign-execution.md`。广告主提出的其他所有写入请求，均按常规流程遵循 `writes.md`。

无论如何，读取操作始终有效，因此规划环节仍具有完整效力：按照与创建广告系列相同的流程，依次执行 `campaign-creation.md` 及其引用的各阶段内容——包括定位、调研、目标设定、`campaign-targeting.md`、`campaign-budget.md`、`campaign-creative.md`——并在 `campaign-execution.md` 应当开始之处停止。切勿执行 `render-campaign-success`，也勿将任何内容描述为已创建、已搭建或已暂停；在广告主发布之前，一切皆不存在。

若拒绝发生在最终创建环节，则已完成的规划方案即为最终设置指南，应在同一回复中直接提供，无需重新规划。

## 广告主可上传的创意素材

请按每条广告分别撰写完整的文案内容——主文案、标题、描述及行动号召语。根据 `campaign-creative.md` 生成的图片属于广告主自行上传的素材，请明确指出该图片所属的具体广告。对于现有的主页帖子或账户媒体资源，请以名称及查找路径的形式提供参考，切勿使用ID标识。

## 设置指南

按广告管理平台构建广告系列的顺序，逐级列出各部分：首先是**广告系列**，然后是每个**广告组**，最后是每条**广告**。在每一层级下，仅列出规划阶段已确定的设置项，并注明广告主需要选择的值：

- 广告系列：目标、名称、特殊广告类别（如适用），以及预算是否归属广告系列层面。
- 广告组：转化归因位置与效果目标、预算与投放时间安排、投放地域、受众年龄，以及已解析的兴趣与语言列表、版位设置。
- 广告：Facebook主页与Instagram账号、格式、素材、文案、目标链接，以及若规划中包含转化追踪，则需注明数据集或像素代码。

请使用 `response-style.md` 中的标签——“Sales”、“Highest volume”——切勿使用 API 返回的值或 ID。不要描述未经验证的界面、菜单或按钮位置；他们需要的是设置名称及其对应的值。请说明花费会在发布后开始，并告知选择 Advantage+ 后，广告管理工具的默认出价方案可能会改变计划所选定的出价。

最后，提供一个 `muse.create_options` 菜单，列出他们发布后仍可执行的操作：调整计划、重新制作创意，或根据计划对广告系列进行核对——该核对属于读取操作，且可正常执行。除非在此对话中已有工具因写入权限问题拒绝过对该账户的操作，否则请主动提出代为创建。
