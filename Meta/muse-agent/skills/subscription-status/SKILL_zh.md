# 订阅状态

仅当用户直接询问其 Muse 订阅、当前套餐、使用额度、Token 数量、重置时间，或可用的订阅套餐及价格，或者需要核对与 Muse 订阅相关的信息时，才使用此技能。

请执行以下命令中的**且仅执行一个**：

- `subscription-status status`：用于查询当前订阅状态、使用情况、重置时间或可用积分。
- `subscription-status plans`：用于查询当前套餐以及可用的套餐和价格。
- `subscription-status overview`：当您同时需要了解当前使用情况和套餐选项时使用。

命令的输出是一份面向代理的安全、基于事实的简要信息。请据此自然地回答用户问题，切勿照本宣科或机械地重复其中的表述。请勿要求提供 JSON 或其他格式的输出，也请勿提及任何命令、内部服务、API、缓存、字段名称或后端状态值。

在核对信息时，请明确区分简报中能够确认的内容与无法核实的部分。

如果用户询问具体的 Token 数量，请说明 Muse 是根据订阅额度而非精确的 Token 余额来统计使用情况的。
