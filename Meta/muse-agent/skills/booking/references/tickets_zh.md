# 活动门票

本参考适用于体育赛事、音乐会、戏剧、喜剧及其他需购票的活动。

## 在提问前先明确活动信息

利用已授权的上下文、日历、票务账户、电子邮件及实时日程，确认以下信息：

- 确切的球队、艺人、演出或活动名称
- 下一场相关活动及其当地时间/日期
- 当存在歧义时，明确主场或客场、场馆、城市以及赛事/赛季
- 历史购票平台、偏好的座位区域、价格范围及观赛视角偏好
- 会员资格、季票权益、预售、粉丝俱乐部福利或持卡人优惠
- 仅将通常的同行人数作为参考，不得假定同行者均会出席

对于“爱国者队的下一场比赛”，请核实官方赛程，并明确“下一”是指近期所有比赛中的下一场，还是当前语境下的下一个主场比赛。只有当两种理解均合理且会导致不同的购票结果时，才继续提问。

## 最低搜索要素

必须明确活动的具体场次及购票数量。座位与预算可根据可靠的历史记录推断为搜索偏好，但不得超出用户明确提出的上限或既定限额。无障碍座位必须明确标注，不得推断。若购票数量问题未获解答，即使用户已回答其他部分，该问题仍视为未解决。在确切数量未知时，切勿擅自调用诸如“优选座位”之类的库存查询，应再次询问。

## 搜索与导流

优先查阅官方日程。通过场馆或可用的票务平台（如Ticketmaster）检索一手票源，包括经认证的预售或账户专属优惠。在合法且有必要的前提下，再比对信誉良好的第三方转售票源，并清晰标注一手与二手的区别。

使用Ticketmaster前，请阅读其命令规范文档`/opt/hatch/skills/ticketmaster/SKILL.md`。Ticketmaster只是本次购票流程中的一个票务提供商，而非替代方案。

搜索结果或购买链接并不等同于完成购票。须通过已登录的浏览器选择具体座位并进入最终确认环节。若开售尚未开始，应告知准确的开售时间，不得谎称票源已售罄。

不得使用未经证实或虚假的票务信息。不得为获取票源而注册付费粉丝俱乐部、办理季票或申请信用卡。

## 按具体座位与实付总价排序

比较以下要素：

- 座位区、排号、具体座位及连座数量
- 视野、距离、侧向角度，以及是否有遮挡或视野受限的标注
- 一手票与二手票的区别，以及卖家或交易平台的保障承诺
- 票价明细、服务费/设施费/订单费、税费及最终实付总额
- 票务形式、送达时效、转让限制及转售政策
- 退票/延期/取消条款
- 实质性的会员、预售或持卡人权益

在实际库存可查的情况下，不得仅凭场馆地图推荐座位。不得在未征得同意时擅自更改日期、场馆、场次、购票数量、座位区域或转售票源。

遮阳、顶棚覆盖、天气暴露及视线遮挡等属性应视为具体的票面说明，不得仅凭侧区或分区名称推断。若无权威来源明确支持该分区或票组具备相应属性，则应声明该信息未经验证；场馆的一般性描述仅能作为最佳推测建议，绝非保证。

## 准备与下单

座位保留时限较短。应保持同一结算页面持续有效，显示保留到期时间，并在审批延迟时及时更新具体座位及总金额。

在最终确认环节，应包含活动信息、场馆、当地日期/时间、购票数量、具体区/排/座、一手或二手状态、费用明细、实付总额、配送方式、转让限制及退改条款。

结账时应使用已保存的票务档案和安全钱包，不得泄露完整的会员或支付信息。请通过订单号以及账户中可见的门票或配送记录进行验证。返回活动详情、座位信息、总金额、安全订单编号、配送状态，以及任何截止日期。如果门票将稍后送达，请明确说明；订单确认并不等同于门票已送达。
