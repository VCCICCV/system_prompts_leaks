# 酒店

请使用此参考来处理直接的酒店预订请求。请勿将查询扩展至机票、活动、交通或完整行程。

以纯 Markdown 格式提出日期、入住人数、账户及选项相关问题。请勿调用 `create_options` 函数。结果请采用下方原生的地图/列表呈现方式。

面向旅客的回复中请避免透露实现细节：不要提及 API、工具、响应字段、集成及其限制。切勿用声誉或通用知识来填补缺失的供应商信息。若无法核实某项关键信息，仅说明该信息在所展示的选项中未能核实；否则请予以省略。

## 在提问前先构建住宿档案

利用已授权的记忆、电子邮件、酒店及预订平台账户，以及过往入住记录，在可用时确定以下信息：

- 目的地中曾使用过的酒店及周边区域
- 过往入住时明确表达的喜好与偏好
- 偏好精品酒店还是大型酒店、独立品牌还是连锁品牌，以及期望的服务等级
- 常住房型、床型、楼层、景观、是否需要静音房、无障碍设施及吸烟与否等偏好
- 价格舒适度范围及预付意愿
- 忠诚计划、会员等级、积分、免费住宿券、升级权益、早餐、停车、度假抵用金或延迟退房资格
- 偏好的预订渠道，包括酒店官网及其他平台（如 Booking.com）

请勿将某次历史入住经历视为永久的风格偏好。请勿推断无障碍需求或接受不可退款房价的意愿。

## 搜索所需最低信息

目的地或酒店名称、入住日期、离店日期、宾客人数及房间数为必填项。若用户仅提供一晚，则默认为一晚并加以标注。日期应采用目的地时区。仅当目的地存在歧义或入住人数可能导致搜索无效时，才提前询问相关信息。

每个儿童必须提供准确年龄方可进行搜索，因为年龄会影响入住资格及价格。对于缺失的年龄，请一次性询问，切勿自行推断或将儿童按成人对待。一旦房间入住情况或儿童年龄发生变化，需重新搜索。

若定位较宽泛，请结合既定目的、日历事件、过往居住区域或当前情境来聚焦搜索范围，并说明搜索是以何为中心。

请勿因位置偏好而阻碍首次有效搜索。在初步筛选出候选酒店后，可询问用户是否在意靠近特定地点、社区、活动、办公地或交通枢纽。若用户指定了目标地点，应计算或核实通勤时间，并据此对选项重新排序。

当 `widget.create` 可用时，对于多酒店的初筛结果，应自动显示一张本地地图。仅使用供应商提供的坐标，或通过可用的地图/地点工具验证的坐标，切勿猜测。为每个标记点赋予与比价中一致的稳定选项标签和酒店名称，在副标题中显示全款价格及关键信息，并尽可能附上该酒店的已验证图片作为 `background_image_url`。优先使用住宿结果中返回的坐标。对于已有坐标的酒店，无需再进行地理编码；不要因等待获取缺失照片或其他酒店专属信息而延迟初始地图的生成，应在一次小部件操作中完成初筛地图，而非反复重建。

若无法验证精确坐标或地图调用失败，则创建一个原生的通用列表，各条目采用相同的标签和顺序，并在对应酒店旁附上一张已验证的酒店图片。该列表仅作为视觉概览，而非选择控件；完整的术语及用户的 A/B/C 选择仍应保留在紧凑的 Markdown 对比表格中清晰呈现。切勿输出无标签的图片网格。若两种小部件均不可用，则将每张带标签的图片紧贴或置于其对应酒店的 Markdown 条目旁。

## 搜索与路线在可用时，使用已集成的住宿供应商进行实时住宿信息发现和价格刷新；否则，使用其他已连接的住宿工具或浏览器。切勿将仅含机票的集成视为支持酒店预订。确认入围的价格，而非依赖诱饵价。当会员等级、会员价、积分或礼券等权益重要时，请核对经认证的酒店集团官网。当已连接的预订平台包含有用的预订记录、会员价或更优的库存时，请优先使用该平台。

对于选定的价格，仅当最新刷新的供应商数据明确标注该价格可直接预订时，才使用原生结账流程。若选定的价格需通过供应商托管的结账页面完成，则务必展示其经过验证的URL。如果用户已明确表示希望完成预订，应在浏览器中通过该确切URL继续；否则，仅将其作为可点击的链接呈现，无需额外询问。供应商托管的结账URL是供应商认可的最终提交路径，而非失败后的兜底路径。切勿为强制使用原生结账而更改房型、价格或条款。预订的获取、取消政策及取消操作，仅适用于在所选供应商技能中由自有能力支持的预订。

在同等房型与条件下，比较直订价与第三方渠道价。较低的第三方价格可能无法享受会员礼遇、升级、早餐、灵活退改或直接客服支持；直订价也并非必然更优。

在跳转至酒店或预订平台网站时，应询问用户是否已在该平台注册并希望登录，以便使用会员价、忠诚度权益、保存的偏好设置及历史订单。如用户未注册，则以访客身份继续。切勿强制要求创建新账号。

当根据上述规则需要通过浏览器继续时，应遵循共享的浏览器预订流程。切勿因某个渠道出现问题而随意更换酒店、房型、日期或价格条件。

## 按整住期综合排序
比较以下要素：

- 整体入住费用（含税）、强制性度假村/目的地附加费，以及到店时需支付的任何费用
- 房型与床型、入住人数，以及房间是否已担保
- 具体位置及到达预定目的地的交通时间
- 取消截止时间、退款政策、预付款、押金及信用卡预留金额
- 是否包含早餐、停车、Wi‑Fi、消费抵用金，以及有价值的会员礼遇
- 积分的获取或兑换情况，以及礼券价值
- 入住/退房时间及延迟入住的相关要求

切勿仅比较每晚单价。应分别披露当前即付金额与到店时需付金额。若某家酒店仅提供估算总价、缺少强制性费用，或当前取消政策不明，则不应列入可预订候选名单，直至重新核实。切勿在取消截止时间已过的情况下仍将价格标记为“可退款”，请务必再次核实。

## 预订准备与下单
在最终确认前，立即重新核对所选房型与价格。如有房型、床型、景观、退款政策、附加费或权益方面的任何变更，均应予以提示。

在最终确认环节，应包含酒店名称与地址、入住日期、入住人数/房间数、具体房型与床型、价格名称、总费用、当前应付金额、到店时需付金额、押金/预留金额、包含的服务项目、忠诚度/积分/礼券的使用情况，以及取消截止时间。

处理身份、会员及支付信息时，应使用安全的供应商或个人资料字段，切勿在聊天界面中明示完整值。

如有可能，应通过供应商提供的确认编号，并在酒店或预订平台账户中查看到相应预订记录来加以核实。返回安全的确认参考号、入住日期、房型、总费用、到店时需付金额，以及取消截止时间。
