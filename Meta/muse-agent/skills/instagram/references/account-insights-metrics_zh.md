# 账户洞察指标

在报告 `account-insights` 结果或解释 Instagram 指标时，请使用以下名称、单位和定义。这些定义来自 Meta 的外部指标目录。请用通俗易懂的语言进行解释，但需保留其含义和单位。

## 解读说明

- 在解释或比较指标时，应明确列出每个指标的计数单位、计数条件、包含的内容类型以及是否为估算值。
- 目录未说明账户中心中的账户如何映射到 Instagram 账户，也未保证这些总计值的排序关系，更未在不同指标间建立账户与事件的关联。因此，请将这些关系视为未知。
- 对于超出已报告计数和算术运算之外的解读，应指明支持该结论的目录依据或独立证据。若两者均无法证实，则应说明尚存的不确定性。在回答某个差距是否能证明因果关系时，仅作此回应，切勿主动提出可能或合理的成因。
- 请使用下方“观看者”指标的定义，不要附加仅限视频的范围限制或最低观看时长要求。
- 描述计算得出的比率时，应分别说明其分子和分母。访问次数或点击次数的比率并不能反映采取某项操作的独立账户占比。
- 访问次数可能包含重复访问，且无法识别独立访客。独立访问账户的数量可能等于或少于访问次数。
- `account-insights` 不提供粉丝数或粉丝增长数据，切勿从人口统计总量推导出相关数值。
- `account-insights` 不返回互动率。如需计算互动率，请明确所采用的公式及输入数据。

## `account-insights` 字段

| 字段 | Instagram 名称 | 单位 | 定义 |
|---|---|---|---|
| `accounts_reached`（或 `reach`） | 触达账户数 | 账户 | 至少看过一次您内容的独立账户数量，包括推广帖子和快拍。与“观看次数”不同，“观看次数”可能包含同一账户的多次观看。估算值。 |
| `viewers` | 观看者 | Accounts Center 账户 | 至少观看过一次您内容的 Accounts Center 账户数量。内容包括 Reels、帖子、快拍、视频、直播视频和广告。估算值。 |
| `content_views` | 观看次数 | 次 | 您内容被播放或展示的总次数，包括重复观看。内容包括 Reels、帖子、快拍、视频、直播视频和广告。 |
| `content_views_by_follow_type` | 按关注者与非关注者划分的观看次数 | 次 | 按“1”关注者、“2”非关注者、“0”未知分类的观看次数。其中，“**来自非关注者的观看次数**”是指由非关注者产生的观看次数占比。 |
| `engaged_accounts` | 互动账户数 | 账户 | 与您的内容产生互动的账户数量，包括在广告中的互动。互动形式包括点赞、收藏、评论、分享和回复。估算值。 |
| `total_interactions` | 内容互动总数 | 次 | 帖子、快拍、Reels、视频和直播视频的总互动次数，包括对推广内容的互动。 |
| `interactions_by_follow_type` | 按关注者与非关注者划分的内容互动 | 次 | 按“1”关注者、“2”非关注者分类的互动次数。 |
| `interactions_by_media_type` | 按内容类型划分的内容互动 | 次 | 按内部内容类型代码分类的互动次数。请勿标注内容类型名称，可报告总数或省略。 |
| `likes` | 点赞数 | 个 | 您内容获得的点赞总数。 |
| `comments` | 评论数 | 条 | 您内容收到的评论总数，已扣除已删除的评论。 |
| `saves` | 收藏数 | 次 | 您内容的收藏次数，已扣除取消收藏的次数。 |
| `shares` | 分享数 | 次 | 您内容的分享次数。 |
| `replies` | 回复数 | 条 | 您快拍收到的回复，包括文字回复和快捷表情回复。 |
| `profile_visits` | 个人主页访问次数 | 次 | 您个人主页被访问的总次数。 |
| `bio_link_taps` | 外部链接点击数 | 次 | 您个人主页上链接的点击次数，不包括对关联 Facebook 个人主页的点击。 |
| `contact_button_taps` | 联系按钮点击数 | 次 | 您商业地址、致电、发邮件或发短信按钮的点击次数。 |
| `follower_demographics_by_*` | 关注者人口统计 | 人 | 根据用户在其个人资料中提供的信息，按年龄、性别（“F”女性、“M”男性、“U”未知）、国家或城市统计的关注者情况。 |
| `online_followers` | 最活跃时段 | 人 | 按天和小时范围统计的关注者在线情况。 |

## 其他 Instagram 指标

`account-insights` 不会返回这些指标。请根据以下定义回答相关问题。

| 指标 | 定义 |
|---|---|
| 展示量 | 您的内容在屏幕上出现的次数，包括在广告中的展示。Instagram 现已针对自然流量内容报告“观看次数”。 |
| 初始播放次数 | 在一次 Reels 会话中，您的 Reels 首次开始播放的次数。统计至少 1 毫秒的播放，不包括重复播放。 |
| 重复播放次数 | 在同一 Reels 会话中，继首次播放之后，您的 Reels 再次开始播放的次数。 |
| 观看时长 | 您的 Reels 被播放的总时长，包括重复播放所花费的时间。 |
| 平均观看时长 | 观看时长除以初始播放次数。以观众为基准的版本则除以观众数。 |
| 快拍浏览量 | 您的快拍被浏览的总次数，包括重复浏览。 |
| 触达账户数（直播视频） | 在直播视频中至少观看 3 秒的独立账户数。为估算值。 |
| 视频 3 秒播放量 | 您的视频至少播放 3 秒的次数，若视频时长不足 3 秒，则按实际时长计算。 |
| 回访观众 | 在过去 90 天内曾观看过您内容，并再次观看该 Reels 的观众。 |
| 总粉丝数 | 在统计周期内关注您的账户数减去取消关注或退出 Instagram 的账户数。为净增长，而非新增粉丝数。 |
| 活跃粉丝数 | 在统计周期内在 Instagram 上保持活跃的粉丝数。 |
| 吸引率 | 最近发布的 Reels 中，超过前 3 秒的观看占比。计算方式为：至少 3 秒的观看次数除以初始观看次数。 |
| 点赞率、收藏率 | 各自的比率均为 Reels 观众中采取相应操作的人数除以初始观看次数，并以百分比表示。 |
| 评论率、分享率 | 各自的比率均为 Reels 观众中采取相应操作的人数除以初始观看次数，并以百分比表示。为估算值，仍在开发中。 |
| 个人主页互动 | 用户与您的个人主页互动时采取的行为。 |

对于此处未列出的指标，请使用 `social_content_performance`，它会通过 `instagram-cli analytics-metric-metadata` 解析目录定义。请勿自行编造定义。
