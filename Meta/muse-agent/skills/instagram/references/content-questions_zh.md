# Instagram 内容相关问题

请利用帖子来回答用户的问题。明确问题所需信息，直接作答，并跳过不必要的查询步骤。

## 阅读可用证据

遵循 Instagram 技能中的“账号关联”部分。阅读公开帖子或 Reels 的链接时无需已连接的账号。当 `instagram-cli accounts` 返回了账号后，请先使用 `instagram-cli post --account-id <user_own_fbid> --url '<exact supplied URL>'` 获取用户提供的完整 URL，再判断该链接是否无法读取。务必确认返回的帖子与用户提供的链接一致。后续操作应使用返回的 ID，切勿通过短码推导 ID。若 `instagram-cli accounts` 未返回任何账号，则不要执行 `instagram-cli post`，而应改用 `social.search` 直接读取该 `post_url`，或借助 `hatch-zeitgeist --raw`，亦或通过浏览器任务（`browser.spawn_task`）进行处理。

请仔细阅读帖子的说明文字、创作者链接以及相关的描述或评论。`instagram-cli media-understanding` 返回的是已存储的文本内容，而非对图片或视频的实时分析；字段为空仅表示未存储相关内容，而非视频中不存在该细节。再次调用也不会带来新的分析结果。

将每次查询的完整 JSON 数据分别保存至 `~/workspace/` 下的独立文件中。检查与问题相关的字段，包括嵌套的描述、商品或品牌标注等。务必阅读整个响应，而不仅仅是前几条内容或其中的 URL。在选取字段之前，先审视返回的数据结构——描述字段可能为列表形式。同时记录每条评论的发布者，并注明是否已查看全部或仅为部分内容。

HTTP 500 或 429 错误并不能证明帖子是私密的或已被删除。如果 `instagram-cli` 返回 HTTP 500 或 429，或者其输出缺乏所需上下文，请选择以下任一备选方案：使用 `social.search` 直接查询该 `post_url`，或在需要已存储的标注信息或媒体位置时使用 `hatch-zeitgeist --raw`：

```sh
hatch-zeitgeist --post-url '<exact supplied URL>' --raw --no-save > ~/workspace/'enriched-<unique-lookup-id>.json'
```

在进一步获取其他媒体信息之前，请先查阅该保存响应中的相关字段。`--raw` 参数会保留 `content_understanding` 字段，而常规社交平台输出通常会省略此项。商品和品牌的标注可能是机器推测的结果，应将其视为线索，未经亲自核实不得断言为确切匹配。即使 `media` 字段为空，缩略图也可能存在。

## 检查尚未解决的视觉细节

请使用展示目标物品的帖子图片或画面帧，而非创作者的头像。务必保存完整的签名图片 URL。成功下载后，再使用本地文件调用 `muse.read` 进行检查。Reels 的缩略图可能显示的并非您所需的时刻。

如果问题所需的视觉细节仍未得到解答，请请求浏览器协助检查。如有条件，可使用 `browser.spawn_task`；否则，将原始 URL 和未解决的细节反馈给上级代理进行核查。要求浏览器任务通过可见控件播放或暂停视频，并使用 `muse.automation` 查看相关帧次。请报告所见内容，以及任何无法播放或打开的部分。同时，要求浏览器任务尽快返回任何可用的直接视频 URL 及其来源。在获得合法的视频数据后，可使用本地 ffmpeg 提取相关帧并进行分析，切勿将视频文件或 URL 发送至第三方转换服务，也不得绕过访问限制。

`browser.open` 仅用于读取页面文本，无法观看视频。它无法访问 instagram.com、facebook.com 和 threads.com 等域名的链接，因此对于帖子 URL 不宜使用此功能，应改用 `instagram-cli` 或浏览器任务。未能看到视频内部内容并不意味着标志或产品不存在。同源的创作者跨平台发布或许能提供缺失的证据，请务必确认两者为同一内容。

## 完成用户任务一旦有了最佳答案，请立即分享。请提供已找到的物品标识及相应链接；若后续核查又有新发现，可对答案进行完善。切勿仅以“稍后会补充”之类的话语草草收尾，而实际上已有可供分享的内容。

如需购买或匹配某件商品，请先参阅购物相关指南，再按要求开展搜索。在询问尺码或偏好之前，务必先确认所描述的物品是什么。只有当具体款式或替代品的选择取决于尺码或偏好时，才提出相关问题。若匹配结果依赖于视觉细节，请将候选图片与原图逐一比对。对替代方案的标注应如实准确。严格遵守购物类问题的验证与呈现规范。若用户明确询问“在哪里购买”，即视为已获得行动许可，无需再次征得同意即可寻找购买渠道。

对于涉及人物或主张的问题，请务必注明明确的来源，并引用可信的公开信息。上传者未必就是图中所描绘的人。切勿仅凭面部特征来识别他人。缺少标签、个人简介或搜索结果，并不能证明某项主张为假或某产品不可用。在将相关信息转交给其他工具或用于回答时，也应一并带上这些注意事项。请明确指出哪些内容尚未得到证实。
