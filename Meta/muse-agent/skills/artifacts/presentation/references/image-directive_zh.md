# 图像生成指令

每个用于演示文稿的 `media.generate_image` 提示都必须是**艺术化引导型**，而非单纯的主题描述，这样才能确保整套视觉呈现风格统一、达到杂志级水准，而不是拼凑的库存图片。调色板的各色值（`primary`、`accent`、`paper`）以及文稿的 `image_style` 均来自您收到的《风格规划》文件。

请按以下顺序依次构建每个提示，然后将其整合为一句完整语句。将 `media.generate_image` 的 `output_dir` 设置为您合同中明确指定的 `artifact_media_dir` 路径（切勿使用简化的 `.src/media/`，否则会解析到主目录），最后将生成结果以内嵌 `data:` URI 的形式插入。

1. **媒介类型**：根据文稿主题选择合适的媒介，并在所有幻灯片中保持一致：
   - 针对现实或商业类主题（如项目推介、季度业务回顾、旅行、产品、美食、房地产等），选用精致的编辑摄影；
   - 针对趣味性、儿童、游戏、健康或概念类主题，则采用单一的插画风格（扁平矢量、水彩、等距透视或3D渲染，三选一）。务必遵循文稿的整体基调——即《风格规划》中的 `StylePlan.image_style` 指定。
   
2. **主体内容**：明确该幻灯片的具体主题。对于操作指南、教育类或概念类幻灯片，图像必须清晰地**展示**相应概念（例如，一张实际体现“引导线”或“三分法”的照片，而非泛泛的相关场景），以便观众一目了然地理解要点。

3. **构图方式**：首先确定图像的**角色**，这将决定画面的取景与布局：
   - **全幅/主视觉**（封面、章节页、宣言页、结束页，或标题/文字覆盖于照片之上的全屏图像）：将主体及细节元素置于画面一侧或上方区域，并在至少一侧及底部边缘留出大面积、平静且细节较少的**负空间**（即常规标题区），以确保叠加的文字清晰可读。遵循三分法构图，切勿将繁杂的主体置于画面正中央，以免遮挡标题。
   - **内容/单元格**（占据双栏的一半、分格/画廊中的一个单元格，或作为图文并置的独立图像栏）：则采取**相反策略**，将主体饱满地居中放置，填满整个画面，**不留**空白负空间。由于文字不叠加于图像之上，预留的空间只会被裁剪成单元格内的无效区域；因此，紧密构图、充满主体的画面在应用 `object-fit: cover` 时能实现干净利落的裁切。

4. **色彩与明暗**：调整图像色调以契合调色板（`primary`、`accent`），使其整体协调，但同时需确保主体鲜明、曝光充足，具有强烈的对比度和丰富的层次感。**切忌使图像过曝或灰淡**：避免出现雾气弥漫、朦胧、过度曝光、高光溢出、近乎纯白、乳浊、平淡或低对比度的效果，更不能让主体与背景融为一体。图像的亮度应与幻灯片背景相匹配（深色背景配浓郁的低光效果，浅色背景则需明亮且富有层次），但醒目、高对比的主体始终优先于柔和融合。避免使用与调色板冲突的色彩。

5. **品质要求**：追求精致质感，杜绝千篇一律的库存感。摄影方面：光线柔和且富有设计感，浅景深，细节细腻，焦点锐利。插画方面：造型简洁，线条粗细均匀，构图均衡。请提供**高分辨率**图像（长边≥1536px），确保在全幅幻灯片中依然清晰锐利，绝不能出现模糊、拉伸、像素化或细节不足的情况。对于**自有素材**照片，同样适用此标准：下载后请使用 `gm identify` 确认其像素尺寸，若长边低于规定值，则不得用于主视觉或全幅画面，而应直接舍弃，不可强行放大。

6. **宽高比**：根据版面需求指定图像比例：侧边栏使用竖版（长边在上），全幅封面使用16:9，以便在应用 `object-fit: cover` 时仅作少量裁剪即可适配容器。

7. **排除项**：图像中不得包含文本、字母、数字、方程式、公式、坐标轴标签、图例、说明文字、水印、徽标、仪表盘或用户界面（使用 matplotlib 路径渲染图表，并将所有标签以样式化的 HTML 形式呈现）；文本区域不得出现杂乱元素。

## 示例

**主视觉图**（标题覆盖照片，因此需留出负空间）：  
> 一张清晨薄雾笼罩的山间湖泊的编辑摄影照片，主体位于右上三分之一处，左下部分为平静空旷的水面与天空，用于放置标题；柔和的金色侧光，色调偏淡并渐变至甲板的纸本色系，浅景深，细节精致，画面比例为 16:9。

**内容单元格**（文本置于其旁，因此需填满画面）：  
> 一张阳光洒满草地的金毛幼犬编辑摄影照片，主体居中并充满画面，自然柔和的光线，浅景深，细节细腻，画面比例为 4:5 的竖版构图，适用于侧栏展示。

## 何时生成

当封面主体为非真实事物时，默认生成封面主视觉图；若封面主体为真实事物（如公司、产品、地点或人物），则应改用图像搜索技能获取素材。对于用于阐释概念的内容图片，请按《authoring.md》中的“图片”章节要求进行制作。指标类、陈述类及财务类幻灯片应保持以文字和数据为主，切勿仅为增加图片数量而额外生成图片。
