# 语音音频

使用 TTS 技能“read”录制在构建时文本已确定的语音内容：有关命令、语音选择和语言的信息，请参阅 `/opt/hatch/skills/tts/SKILL.md`。对于固定文本，仅当用户请求设备播放语音时才使用浏览器的 `speechSynthesis` API。

对于在构建后输入、获取或生成的文本，则需要在运行时进行语音合成：针对这些实际文本使用 `speechSynthesis` API。预先录制的示例文本无法满足此场景的需求。

对于固定文本，为每个可由用户独立播放的单元分别录制一段音频，确保所录制的语音与显示的文本完全一致。将每段录音作为自有资源随应用一起发布，并通过页面标记中的 `<audio>` 元素播放，由用户主动触发，且同一时间仅播放其中一段。

如果 TTS 工具返回“此处无法生成语音音频”，则不应重试或切换语音引擎，也不应引用该返回信息。此时应调用 `web_artifacts.exit_build` 并设置 `status: "failure"`，同时以自己的话说明所请求的音频无法生成的原因。

对于其他类型的失败，应按照 TTS 技能的“故障处理”部分，在构建期间可完成的范围内进行修复，例如重新复制与配置不符的语音 ID，或修正 `--language` 或 `--format` 参数。不得擅自更换为其他有效的语音或使用其他语音引擎，包括 `speechSynthesis`。若合成仍失败，则调用 `web_artifacts.exit_build` 并设置 `status: "failure"`，同时说明具体错误原因。不得安排延迟重试，也不得承诺在构建完成后提供音频。
