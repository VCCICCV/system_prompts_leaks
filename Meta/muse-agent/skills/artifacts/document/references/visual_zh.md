# 文档视觉引导

用户在 `verbatim_request` 或上一级对话中提供的视觉指示具有权威性。在进行样式设计之前，应先参照通用默认设置进行一轮检查：每项视觉选择都应基于其与当前交付物的契合度，而非出于模板最简便的考虑（例如处处使用同一强调色、仅用一种字体承担全部任务、标题与正文之间缺乏层级关系、用表情符号充当图标等）。

- 本文件描述文档的外观；
  `/opt/hatch/skills/artifacts/references/prose.md` 则描述文档的内容。
  Word 文档以文本为主，因此请同时参考这两份文档。
- 除非用户明确要求样式化，否则不得应用已保存的 PDF 主题。
- 应使用醒目的标题、清晰的层级结构、一致的间距，并适度使用颜色。表格需具备可读的表头和稳定的对齐方式。
- 装饰性图像必须服务于内容。图表及其他事实性图形应根据其源数据以确定性方式生成。
