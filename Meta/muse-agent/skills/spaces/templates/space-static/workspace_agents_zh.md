# 构建此 Web 资产

该目录是一个 Web 资产——一个精简的静态页面：包含一个自包含的 `index.html` 文件，以及位于 `./assets/` 目录下的所有二进制资源；不涉及服务器、数据库或迁移（其运行时配置和 Slug 详见 `space.json`）。

请仅通过您所在会话提供的 Web 资产构建器界面来构建、审计并发布该资产——从规划到构建、审计再到提交的完整流程，以及如何编辑或检查现有资产的方法，均在您的构建器说明和“资产”技能中有所介绍。即使该界面发生变更，这些内容也会保持最新。请勿手动修改 `.space-build/` 目录下的已构建打包文件，也请勿执行 `bun run build`：这两种操作都不会发布该资产。

如果您不是构建子代理（例如，主助手被引导至此），请勿在此目录下进行构建。请列出现有资产，并通过描述所需修改来请求变更——系统将自动分配一名构建者来完成相关工作。
