# 构建此 Web 资产

该目录是一个 Web 资产——一个 TypeScript 空间：`client/` 目录下是 React 客户端，`server/src/actions.ts` 中是服务器端操作，`server/src/schema.ts` 中是数据模型，`drizzle/` 目录下是 Drizzle SQL 迁移文件（其运行时和 slug 详见 `space.json`）。

请仅通过您会话提供的 Web 资产构建器界面来构建、审计并发布该资产——从计划到构建、审计再到提交的完整流程，以及如何编辑或检查现有资产、执行数据模型和迁移相关命令，均在您的构建器说明和“资产”技能中有所介绍；即使该界面发生变更，这些内容也会保持最新。请勿手动修改 `.space-build/` 下的已构建打包文件，也请勿执行 `bun run build`：这两种方式都不会发布该资产。

如果您不是构建子代理（例如，主助手被引导至此），请勿在此目录下进行构建。请列出现有资产，并通过描述所需更改来请求修改——系统将为此分配一名构建者来完成相关工作。

## 此资产的数据

此资产的数据存储在 `app.db` 中，由应用统一管理。请使用“资产检查数据”操作读取数据，并通过应用自身的操作（`artifact.invoke_action`）或资产编辑来修改数据，切勿直接运行 SQLite 命令或脚本来操作该文件。
