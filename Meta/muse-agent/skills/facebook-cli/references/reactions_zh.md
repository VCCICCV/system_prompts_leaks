# Facebook 反馈

查看 Facebook 帖子的反馈汇总。

## 命令

```bash
facebook-cli post reactions read --post-id <帖子ID>
```

**选项：**
- `--post-id`（必填）：要读取反馈的帖子 ID

该接口仅返回反馈的**汇总信息**（总数量及各类型数量）。此命令无法获取单个反应者的列表。

## 响应字段

响应中的聚合数据位于 `summary` 下：
- `summary.total_count`：帖子的总反馈数
- `summary.reaction_counts`：`{ reaction_type, count }` 数组——按类型细分（点赞、爱心、哇、哈哈、伤心、愤怒、感谢、关心）

`data` 为空数组（不返回单个反应者列表）。

## 操作规则

1. 展示反馈时，需包含 `summary.reaction_counts` 中的类型细分（点赞、爱心、哈哈、哇、伤心、愤怒），以及 `summary.total_count` 的总数量。务必附上帖子的永久链接，切勿直接显示原始帖子 ID。此命令无法提供单个反应者的姓名（“谁点了赞”或“谁进行了反应”）；若用户询问是谁进行了反应，请说明无法提供反应者列表，并改以各类型数量作为回应。
2. 当用户询问“最近”或“最新”的反馈时，务必在回复中明确所使用的日期范围（例如：“以下是过去7天内有反馈的帖子”）。
3. 在比较不同帖子的反馈时，应基于实际数据进行清晰的数值对比，并为每个被比较的帖子附上链接。
4. 切勿使用“非常受欢迎”或“爆火”等主观性表述，除非有具体数字支撑。
5. 当用户使用非正式用语按类型筛选反馈时（如“搞笑的”、“伤心的反馈”、“笑的那些”），请先确认其具体指代的 Facebook 反馈类型再继续操作。常见映射如下：“搞笑”/“笑的”→ 哈哈，“伤心”→ 伤心，“愤怒”/“生气的”→ 愤怒，“爱心”/“爱”→ 爱心。若映射存在歧义，请请用户确认。
