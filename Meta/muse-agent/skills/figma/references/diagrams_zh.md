# FigJam 图表

`generate_diagram` 可根据 Mermaid 生成可编辑的 FigJam 内容。可用于绘制流程图、架构图、时序图、ER 图、状态图和甘特图。它不支持饼图、思维导图、维恩图、类图、C4 图以及 Mermaid 时间线。

请基于源代码、规格说明、现有的 Figma 内容，或用户提供的具体回答来构建图表。切勿为了使图形看起来完整而凭空添加实体或边。

为确保 Mermaid 兼容 Figma 的渲染器，请注意以下事项：

- 不要使用表情符号、HTML 标签，或转义的 `\n` 换行符作为标签。
- 节点 ID 应采用简单的驼峰命名法；不要使用 `end`、`graph` 或 `subgraph` 等保留字作为 ID。
- 包含标点符号或括号的标签需用引号括起。
- 不要依赖时序图中的注释或甘特图的样式，因为渲染器会将其移除。如有必要，可在后续使用 `use_figma` 添加注释，但前提是这些注释确实能提升表达效果。

在调用 `generate_diagram` 之前，请勿先调用 `create_new_file`；图表生成功能本身即可创建新的 FigJam 文件。若进行迭代，请传递现有的 `fileKey`，以免用户积累重复的草稿文件。在删除任何内容之前，请询问用户是保留两个版本，还是仅保留最新版本并替换旧版图表。

若连续两次生成结果均不理想，请停止重新生成，并询问用户具体需要修改的部分。
