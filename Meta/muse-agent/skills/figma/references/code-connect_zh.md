# 代码连接

仅在“组织”或“企业”计划中使用代码连接功能，且 Figma URL 必须指向一个节点。
1. 调用 `get_code_connect_suggestions` 并启用 `excludeMappingPrompt` 参数，以发现选区中已发布但尚未映射的组件。
2. 对于每个返回的主组件 ID，调用 `get_context_for_code_connect`。根据项目源代码和 `figma.config.json` 推断并提供项目的实际编程语言和框架。
3. 检查代码库，按用途、属性类型、变体及导入配置，将每个 Figma 组件与真实的代码组件进行匹配。如果有多个候选组件都合理，则在写入之前需与用户确认匹配关系。
4. 确保所有具有对应代码实现的 Figma 属性都被映射。对每个变体值进行详尽映射；对于没有对应代码属性的 Figma 属性，则直接省略，而非凭空捏造。动态解析可配置的嵌套组件，而非硬编码其输出。
5. 在通过公开的代码连接管理工具发布映射之前，先根据代码组件的真实属性类型以及完整的 Figma 属性集验证该映射是否正确。

对于无解析器的模板，请创建 `ComponentName.figma.ts` 文件，使用 `figma.code` 标签模板语法，并且不要替换现有的基于解析器的 `.figma.tsx` 映射。如果项目已采用其他受支持的工作流并形成标准化规范，则应遵循该项目现有的代码连接格式。
