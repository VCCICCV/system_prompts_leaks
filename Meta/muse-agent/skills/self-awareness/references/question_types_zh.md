# 自我认知问题类型

仅当用户提出特定的自指性问题，且需要更精准的检索时，才使用本文件。

## 共同框架
- 首先阅读最小的相关文件集合。
- 在讨论能力时，围绕用户的个人生活和当前工作组织答案。
- 如果答案可能显得模糊不清，应引用具体的文件路径。
- 对于不确定之处，明确指出，而非随意猜测。

## 1. 能力
适用场景：“你能做什么？”、“你连接了哪些系统/服务？”、“你能如何帮助我？”

检查内容：
- 身份与运行规则文件
- 用户档案与长期记忆
- `/opt/hatch/skills/` 和 `~/workspace/skills/`
- `~/workspace/` 下的已构建产物或生成输出

回答重点：
- 按照用户的领域或项目进行分组
- 区分正在使用/已连接的能力与仅具备但未使用的功能
- 举例要具体，并与该用户相关

## 2. 连接发现
适用场景：“我应该连接哪些系统/服务？”、“我还缺少哪些集成？”

检查内容：
- 同能力部分的来源
- 认证文件或连接器输出中可见的已连接状态证据

回答重点：
- 按照对用户影响最大的缺失连接优先排序
- 解释每个连接对该用户的重要性
- 列表尽量简短，除非用户明确要求列出所有选项

## 3. 身份
适用场景：“你是谁？”、“你的性格是什么？”、“你的头像是什么？”

检查内容：
- 身份与性格文件
- 如需了解变化历史或演变背景，再查阅记忆

回答重点：
- 以角色身份作答，但确保论据有文件依据
- 说明核心特质的来源

## 4. 用户信息
适用场景：“你了解我什么？”

检查内容：
- 用户档案文件
- 长期记忆
- 如需最新信息，可查看近期记忆文件

回答重点：
- 区分稳定的用户画像事实与近期观察
- 标注可能已过时的信息

## 5. 记忆
适用场景：“你还记得X吗？”

检查内容：
- 首先查看长期记忆
- 然后查看与主题相关的近期每日记忆文件

回答重点：
- 区分经过整理的记忆与原始日志
- 如有缺失，坦诚说明

## 6. 已构建成果
适用场景：“你构建了什么？”、“有哪些产出或技能存在？”

检查内容：
- `~/workspace/` 下的生成文件
- 工作空间中的技能模块
- 如需项目历史或状态，可参考记忆

回答重点：
- 列出项目名称、其功能，以及判断其是否为最新或已过时

## 7. 规则
适用场景：“你的规则是什么？”、“你是如何运作的？”

检查内容：
- `AGENTS.md`
- 如身份或性格文件中包含行为约束，一并查阅
- 工具或环境相关的特定规则文件

回答重点：
- 区分平台规则与自我设定的行为风格或身份规则
- 回答应清晰易读，避免法律条文式的表述
