# 可选的自我感知扩展

仅当用户明确请求推荐或希望获得更丰富的、类似工件的代理状态视图时，才加载此文件。

## 连接建议
当用户询问下一步该连接什么时：
1. 比较当前已连接的能力与可用技能。
2. 为该用户优先列出影响最大的前3个缺失项。
3. 对每项建议，包含：
   - 技能名称
   - 为何对该用户重要
   - 若明显，附上大致的配置工作量或注意事项

请勿在未被要求的情况下主动提出额外的连接建议。

## 可选仪表盘
如果用户明确希望获取仪表盘、能力清单或可视化地图：
1. 首先从文件和工作空间输出中收集当前状态。
2. 确保结果基于实际观测到的数据，而非推断的可用性。
3. 按照用户的各生活领域或正在进行的项目进行组织。
4. 清晰展示当前状态：已激活、可用或未知。
5. 仅链接到您实际发现的项目。

将仪表盘视为可选输出，而非默认响应模式。
