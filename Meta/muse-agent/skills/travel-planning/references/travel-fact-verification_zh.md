# 旅行事实核查

本流程定义了航线归一化、资格输入以及与后续机场、边境和中转相关主张的来源归属。

## 对每一段航程独立进行归一化处理

在对某段航程进行推理之前，先记录该航程的相关事实：

- **出发地：** 记录代码、城市、国家或地区，以及适用的边境或海关区域。
- **目的地：** 记录代码、城市、国家或地区，以及适用的边境或海关区域。
- **时间信息：** 在已知的情况下，记录当地时间的起飞和到达日期与时间。
- **服务信息：** 在已知的情况下，记录承运航空公司及航班号。
- **官方分类：** 在有可用信息时，记录航空公司或主管部门公布的分类。
- **航站楼信息：** 在有可用信息时，记录航站楼、来源标识及获取时间。
- **后续环节：** 记录紧随该航程之后的入境、海关、行李提取、中转、衔接或值机等步骤。

根据当前权威的位置数据核对并确认每个机场代码。基于每段航程自身的始发地和目的地及其证据对其进行分类，不得从相邻航段复制国内、国际、空侧、预先通关、免入境或航站楼标签。当始发地与目的地所属国家不同时，除非权威来源证明存在路线特例，否则应将该航程归为国际航段；当始发地与目的地所属国家相同时，在进行分类前应查阅权威来源以确定是否存在特殊的边境或海关制度。请使用下文“将来源与主张对应”中的信息源，针对具体航程及出行日期逐一核实各项后续主张。

## 限制资格输入范围

个性化入境或过境资格的判定仅以现有输入中的最低必要事实为依据：国籍、护照签发国及证件类型、居留或签证状态、旅行目的，以及停留或过境时长。若缺少必要事实，则说明一般适用的流程，并将个性化资格标记为未解决。不得从相邻行程上下文中推断缺失的资格信息，且在常规规划阶段不得索取或留存护照号码。

## 将来源与主张对应

针对每一项后续主张，应由负责该事实的权威机构予以核实：

- 入境、过境、签证、入境申报、护照及海关规则，由政府移民或边境管理部门负责；
- 航站楼、衔接、行李、中转柜台及值机规则，由承运航空公司或机场管理部门负责；
- 快速通道资格、开放时间、接机地点、包含内容及公布价格，由指定机场或服务运营商负责；
- 地面中转时长，以当前的航线或导航证据为准；
- 可靠的第三方平台或近期旅客反馈仅用作定性参考，不得将其作为入境要求或官方服务的唯一证明。

每项规则均需针对出行日期进行核实，并记录来源标识、来源网址（如可获取）及获取时间。若无权威来源能够确立某项后续主张，则将其标记为未验证。任何依赖于该主张的建议均应以该主张得到解决为前提。

不得将通用或记忆中的排队时间当作当前事实呈现。若不存在官方的实时等待时间来源，则应将任何估算标注为历史数据或轶事。快速通道的推荐应基于已验证的抵达流程、用户现有的约束条件，以及该服务已验证的公开条款。

## 区分建议与购买

将运营分析及建议保留在本技能范围内。当 `/opt/hatch/skills/travel-planning/SKILL.md` 中的预订触发条件满足时，应用 `/opt/hatch/skills/travel-planning/references/booking-handoff.md`。将每一段已归一化的航程、所需的资格输入，以及已验证的来源记录，添加至该交接中定义的候选输入中。

对于机场接送服务，仅比较能够满足以下所有条件的选项：确切的机场、航站楼、到达时间、乘车人数、行李数量及目的地。如果没有任何可用工具能够完成所选的接送服务，则将该外部操作指派给责任清单中的用户。
