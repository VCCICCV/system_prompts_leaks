# 航班行程发现

在日期、机场、经停点或多个城市顺序尚未确定的情况下，可先使用行程发现功能，找到合适的航线组合，再进行实时报价的比价与预订。对于日期和旅客信息均已明确的简单行程，可跳过此步骤，直接交由 Booking 等平台进行实时搜索与预订。

## ITA Matrix 的帮助场景

ITA Matrix 可协助您探索：

- 开放式往返及多城市行程顺序；
- 灵活的出行日期或邻近的起降机场选择；
- 直飞与中转、中途停留之间的权衡；
- 航空公司、航空联盟、中转机场或出发/到达时段等限制条件；
- 影响住宿、接驳或固定活动安排的航班时刻规律。

ITA Matrix 是一款用于探索的工具，其结果并非已锁定的行程、实时预订报价，也不是证明 Duffel 或航空公司官网当前能够销售相同行程与票价的依据。请勿将其作为每次航班查询的必经环节。

## 使用只读浏览器任务

由于 ITA Matrix 官网（`https://matrix.itasoftware.com/search`）是一个交互式网页流程，请使用 `browser.spawn_task` 启动官方搜索，并为该任务提供一份独立且完整的简报。浏览器任务不会继承对话上下文，需包含以下内容：

- 确切的出发地与目的地，以及允许的邻近机场；
- 出行日期或日期范围，以及行程顺序；
- 旅客人数及舱位需求；
- 最大中转次数，以及任何关于航空公司、机场、时段、过夜停留、自行转机或分段购票的限制；
- 比较目标，例如最短实用航线、最佳抵达时间，或具有参考价值的低价模式；
- 明确指示仅用于研究，不得进行购买，并在返回页面时一并附上标准化的候选行程详情及页面获取时间。

请勿包含旅客姓名、证件信息、支付详情等行程探索阶段无需使用的个人数据。ITA Matrix 的研究会话并非航空公司的结账流程。

## 记录稳定的行程标识
针对每个候选方案，按顺序记录每个航段的信息：

- 当地出发日期与时间；
- 起降机场代码；
- 市场营销承运航空公司及航班号；
- 如与实际运营航司不同，还需记录运营航司及航班号；
- 当地到达日期与时间，包括次日到达的情况；
- 中转机场及转机时长；
- 舱位等级，以及各航段舱位是否一致；
- 结果是单一票价/单张机票，还是尚无法确定。

同时保留搜索输入参数、来源、获取时间，以及任何显示的票价或票价构成。显示金额仅为参考性的规划信号，应与后续的实时总价区分开来。除非实时预订方能确认相同的商业条款，否则不要将票价基础、订座舱位或出票航司视为已锁定。

仅凭航班号并不能唯一标识一条航线。代码共享、实际运营航司、重复航班号、当地时间边界、机场互换以及时刻调整等因素，都可能导致表面相似的方案实质上并不相同。

## 提供精简的候选方案集
返回两到四个能够体现真实权衡的候选方案，避免直接输出原始结果。针对每个方案，简要说明：

- 整体航线及重要当地时间；
- 总行程时长、中转次数、过夜或更换机场的风险；
- 该方案为何更优或更劣于其他方案；
- 显示的参考金额、币种及获取时间（如有）；
- 在实时预订验证前仍存在哪些不确定因素。

当费用、票务结构或适用的旅客总数尚不明确时，不得仅凭价格高低对选项进行排序。亦不得仅凭通用的舱位等级或票价品牌标签，就断言某条航线可退款或可变更。

## 故障与备选方案
验证码、机器人防护墙、日期选择器失效、结果不完整或浏览器会话中断等，均属于来源端故障，并非航班不存在的证据。请勿在同一问题上反复尝试，而应在行程条件足够明确时改用实时供应商进行搜索；若规划仍需更多支持，则切换至其他可靠的时刻表来源；或如实说明现有证据的局限性。当用户选择某个候选方案，或在需要价格或可用性信息以做出选择时，请继续参考
`/opt/hatch/skills/travel-planning/references/booking-handoff.md`。请勿引导用户离开当前界面重新执行 ITA Matrix 搜索。
