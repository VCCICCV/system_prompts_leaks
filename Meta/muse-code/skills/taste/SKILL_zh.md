# 反“油腻”：前端设计禁忌

在设计 UI 或页面时，哪些事情绝对不要做。这是一套过滤规则，而非设计风格；它从不规定具体的外观。如果同时叠加多项这些“禁忌”，一眼就会让人觉得像是 AI 生成的。本规则具有自适应性：若用户或其他专业需求提出了特定要求，应优先满足那些要求；这些只是默认建议，而非强制覆盖。

- 使用紫色、靛色或紫罗兰色作为强调色，或采用紫到蓝的渐变作为主视觉（这是 AI 设计的典型特征）
- 使用 `bg-clip-text` 的渐变文字作为标题
- 将米白色（`#faf8f4`）作为全页背景
- 使用极光般的色块、发光的彩色阴影，或让每个卡片都带有相同的发光效果
- 全局使用 Inter 字体，或将 Geist、Space Grotesk、Instrument Serif、Roboto 或 Arial 作为唯一的字体选择
- 正文使用 gray-400 或 gray-500 颜色
- 整个页面只有一种字体粗细和大小（缺乏层级感）
- 在每个区块上方添加全大写、紧密字距的微小装饰文字
- 主视觉区域采用居中排版，包含眉标、标题和两个行动号召按钮
- 每处都使用相同的三栏功能卡片布局，且每个卡片内放置一个圆角方框中的 Lucide 图标
- 使用超过 8 个词、字号 48px 以上的空洞标题
- 所有内容一律采用网格布局
- 相同的眉标-标题-三卡片区块连续重复出现
- 对所有元素统一应用 `rounded-2xl` 或单一固定半径的圆角
- 在每个界面元素上叠加毛玻璃模糊、边框和阴影效果
- 卡片在悬停时放大 5% 的动效
- 使用表情符号作为功能图标（🚀 ⚡ ✨ 🎯 💡）
- 左侧带强调边框的卡片、圆角元素上的彩色边框，或卡片套卡片的设计
- 页面滚动时，所有元素都统一使用淡入或上滑的动画效果
- 动画效果未考虑 `prefers-reduced-motion` 用户偏好
- 添加毫无实际意义的手绘风 SVG 精灵图案
