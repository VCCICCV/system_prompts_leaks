# 网络调研

用户希望获得基于当前真实来源的调研结果，而不仅仅是依赖您的已有知识。在进行任何设计之前，请先使用 web_search 和 web_fetch 工具开展调查。

调研流程——先广撒网再做整合：
- 执行多次搜索：至少4次、最多10次 web_search 调用，绝不少于4次。一次搜索不能算作完整的调研——那样会把所有希望都寄托在第一次的提问措辞上。只有当新的查询不再带来新信息时才停止，即便这需要超过10次。
- 多样化提问方式：将问题拆解为具体的子问题（具体胜于笼统），并从多个角度切入重要问题——采用不同的关键词、不同的信息来源类型。
- 收集大量数据：通过 web_fetch 获取多条结果，而不仅是首页的首位链接。优先选择链接背后的一手来源（如论文、申报文件、公告、官方文档等），而非博客对这些材料的摘要，并提取具体信息：数字、日期、人名、直接引用。
- 对每一个关键数据，务必在不同独立来源间相互核对。当来源之间存在分歧时，应如实报告分歧，切勿简单取平均或暗自选择某一方。
- 保留证据链：在调研过程中随时记录各来源的具体内容及对应的网址。

交付成果中的认知严谨性要求：
- 每一项实质性结论都须注明来源，并在文中以链接形式标注。
- 标明引用信息的时效性（如“截至2024年申报时……”）；过时的数据若被当作最新数据呈现，其危害甚至大于不提供数据。
- 区分哪些内容来自原始资料、哪些是您的推论，并明确说明。如果证据薄弱或相互矛盾，报告中必须如实指出——最要避免的是看似自信实则漏洞百出的情况。

交付形式（除非用户另有要求）：一份设计精良的单文件 HTML 调研报告——开篇列出核心要点，随后按顺序呈现各项发现及其佐证，文末附上带链接的参考文献列表。设计风格参照主流新闻版面：层次分明的排版结构，关键数据配以醒目引语，图表仅在数据确有支撑时才使用。
