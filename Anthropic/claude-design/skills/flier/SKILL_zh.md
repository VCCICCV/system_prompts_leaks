# 宣传单

设计一份可供印刷的单页宣传单，以一个自包含的 HTML 文件呈现：严格限定为一页，且页面尺寸固定。

页面设置：
- 首先调用 `copy_starter_component`，组件类型为 `"doc_page.js"`，然后将宣传单构建为一个明确分页的页面：`<doc-page><section class="page" id="flier">…</section></doc-page>`。该组件负责管理页面框、打印时隐藏的桌面背景、分页规则以及所有印刷相关的几何布局——请勿自行编写 `@page` 规则、`body` 背景或硬编码纸张尺寸，也切勿添加任何与印刷相关的元信息。打印对话框必须显示为 1 页。
- 宣传单将以全出血的固定页面框进行打印，溢出部分被裁切隐藏——默认为 Letter 尺寸，用户导出时可选择其指定的纸张（如 Letter、A4 等），因此超出页面框的内容会被裁剪，绝不会重新排版。请确保设计使内容填满整个页面框，并在 Letter 和 A4 尺寸下均无重叠。
- 页面为全出血设计：宣传单应自带内边距——每边至少保留相当于页面宽度或高度 4% 的视觉留白，并确保所有内容均位于此范围内。
- 切勿使用视口单位（vh/vw）——它们跟随的是浏览器窗口，而非页面。

宣传单通常在较远处、快速浏览时阅读，用时不超过三秒：
- 以一个主导元素为主——通常是不超过 6 个词的标题——字号需足够大，能在房间另一端清晰辨认（建议 8cqh+），其余内容应明显处于从属地位。
- “五个 W”要素紧密排列，便于快速扫描：what（什么）、when（何时）、where（何地）、cost（费用）以及一种行动方式（二维码链接、电话号码或可撕下的部分）——切忌分散于正文之中。
- 使用纯色块和矢量图形取代照片与渐变；高对比度；正文字体采用近黑色，印制于浅色纸张上。
- 充足的留白胜过过多文字——精简文案，直至层级关系清晰易见。
- 可选：在底部边缘设置可撕下的条状区域（一排窄单元格，左侧带虚线边框，其中的文字旋转放置），供用户撕下电话号码。

检查打印预览：确保无内容被裁切、无溢出至第二页，且颜色在灰度模式下仍具表现力。
