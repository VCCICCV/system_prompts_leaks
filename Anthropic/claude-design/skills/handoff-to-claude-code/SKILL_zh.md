# 交接给 Claude Code

创建一份完整的交接文档包，以便使用 Claude Code 的开发人员能够在实际代码库中实现此设计。

### 步骤

1. 在项目目录中创建一个交接文件夹：
   ```
   mkdir -p <project-folder>/design_handoff_<feature-name>/
   ```
   使用从设计中提取的、具有描述性的功能名称（例如 `design_handoff_onboarding_flow`、`design_handoff_settings_redesign`）。

2. 在交接文件夹中创建一个 `README.md` 文件，包含以下部分：

#### README.md 结构

```markdown
# 交接：《功能名称》

## 概述
简要说明此设计的用途及其达成的目标。

## 关于设计文件
明确指出本包中的文件是**以 HTML 形式制作的设计参考**——展示预期外观与交互的原型，并非可直接复制的生产代码。说明任务是在目标代码库的现有环境中（React、Vue、SwiftUI、原生等）按照其既定的模式和库来**重现这些 HTML 设计**；如果尚无现成环境，则需为项目选择最合适的框架并在此框架中实现设计。

## 还原度
明确说明本次对话中生成的线框/原型属于：
- **高保真（hifi）**：像素级精确的样稿，包含最终的颜色、字体排版、间距及交互效果。开发者应利用代码库现有的库与规范，逐像素还原 UI。
- **低保真（lofi）**：仅显示结构与流程的线框或粗略布局。开发者应以此作为布局与功能的参考，但样式部分需采用代码库已有的设计体系。

## 屏幕/视图
针对设计中的每个屏幕或视图：
- **名称**：该屏幕的命名
- **用途**：用户在此处的操作
- **布局**：详细描述布局（网格结构、弹性方向、宽度、高度、外边距、内边距）
- **组件**：列出每个 UI 组件，包括：
  - 位置与尺寸
  - 颜色（若为高保真，请提供准确的十六进制值）
  - 字体排版（字体族、字号、字重、行高、字间距）
  - 圆角、阴影、边框
  - 鼠标悬停/激活/聚焦状态
  - 内容/文案（使用的准确文本）

## 交互与行为
- 点击事件处理与导航流程
- 动画与过渡效果（持续时间、缓动曲线、属性）
- 鼠标悬停状态
- 加载状态
- 错误状态
- 表单验证规则
- 响应式行为（如适用）

## 状态管理
- 需要哪些状态变量
- 状态转换及其触发条件
- 数据获取需求（如有）

## 设计令牌
列出所有使用的设计值：
- 颜色（附带十六进制值）
- 间距系统
- 字体排版系统
- 圆角半径值
- 阴影值

## 资源
列出设计中使用的所有图片、图标或其他资源，以及它们的来源。

## 文件
列出项目中包含该设计的 HTML/CSS/JS 文件，以便开发者参考。
```

3. 将相关设计文件（HTML 原型、组件文件等）复制到交接文件夹中。

4. 使用 `present_fs_item_for_download` 工具，传入交接文件夹路径，让用户可以将其打包下载为 ZIP 文件。

### 重要提示

- 在尺寸、颜色、字体排版等方面务必做到精确无误——开发人员将完全依赖这份文档。
- 务必在 README 中开宗明义地说明，所附 HTML 文件仅为**设计参考**，用户所描述的行为应理解为在目标应用的现有环境中重现这些设计（或在尚无环境时选择最适合的框架），而非直接交付这些 HTML 文件。
- 如果设计中使用了 Anthropic 的品牌资产，请提醒开发者在代码中沿用现有的品牌体系。
- 创建完成后，询问用户是否需要在文档中加入设计截图；默认情况下不包含截图。
- README 应具备自洽性——即使未参与本次讨论的开发者，也应能仅凭 README 实现该设计。
