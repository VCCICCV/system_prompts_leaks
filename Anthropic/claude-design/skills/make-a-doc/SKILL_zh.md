# 创建文档

创建一份文档（简历、单页介绍、备忘录、信函、报告、指南、论文）。首先确定用户希望采用哪种版式——这两种版式的导出方式截然不同：

**流动页面**——文本按需自动排布在标准纸张（Letter/A4）上并适时分页：适用于报告、备忘录、信函、论文、指南等。开始时调用 `copy_starter_component`，传入 `kind: "doc_page.js"`，然后在 `<doc-page size="letter" margin="0.75in">` 标签内以常规的流式 HTML 编写整篇文档。该组件负责管理纸张、桌面背景及所有打印布局相关设置——请勿自行编写 `@page` 规则、正文背景、分页容器 `div`、通过 `break-after: page` 模拟的假分页，或在多栏网格内的元素上使用 `break-inside: avoid`（因为网格仅在行之间分页，若某一行无法容纳而被拆分，会在页面上留下空白区域）。

流动页面的打印规则：多栏文本应使用 CSS 列布局（`column-count` + `column-gap`；跨栏标题使用 `column-span: all`；窄列中启用 `hyphens: auto`——需在 `<html>` 元素上指定 `lang` 属性），切勿使用并排的 Flex 或 Grid 布局——只有真正的 CSS 列才能实现跨页流动与分页。对于必须从新页开始的内容（如章节、附录），使用 `break-before: page`；将需要整体保留的自定义区块（如侧边注、数据卡片、信息框）加入 `break-inside: avoid` 规则，并确保每个区块的高度均小于一页——该组件已默认将标题与其内容保持在一起，保证图片/代码/表格行完整不被拆分，并抑制孤行与寡行现象（可将 `orphans: 3; widows: 3` 的设置扩展至自定义文本块）。长表格应添加 `<thead>`，使表头在每一页重复出现。内容中不得使用 `position: fixed`/`sticky`，也不得使用视口单位——固定元素会印在每一页上（页眉页脚应放置在组件的插槽中），而 `100vh` 在打印时会导致尺寸错乱。

**固定版面**——设计需精确填充一张固定尺寸的页面：海报、信息图、社交媒体配图、证书等。无需使用起始组件——直接按实际像素尺寸构建，在顶层元素上明确指定 `width`（若高度也固定，则同时指定 `height`），导出时 PDF 页面会自动调整为该尺寸。请勿为其编写任何 `@page` 规则。

样式规范（两种版式通用）：正文字号 14–16px，行高宽松（1.55–1.7）；标题层级清晰；配色克制。表格应包含表头行，并使用细线边框；图片和代码块均应配有简短说明。文档应以自身标题 `<h1>` 作为首个正文元素（若粘贴内容的第一行已是标题形式，可将其作为 `<h1>`，而非另设独立的页眉）。
