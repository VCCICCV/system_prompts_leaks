# 前端设计

在设计不受现有品牌或设计系统约束的前端/界面时，请遵循本指南。打造独具特色的 HTML，并对美学细节与创意选择给予格外关注。

### 设计思维

在编码之前，务必理解项目背景，并坚定地确立一个鲜明的美学方向：
- **目的**：这个界面要解决什么问题？谁是它的用户？
- **基调**：选择一种极致风格：极简至简、极繁混乱、复古未来、有机自然、奢华精致、趣味玩具、杂志风、粗野主义、装饰艺术几何风、柔和粉彩色系、工业实用风等。可从中汲取灵感，但最终的设计应忠实于所选的美学方向。
- **差异化**：是什么让这个设计令人过目难忘？最能让人记住的亮点是什么？

选定清晰的概念方向，并以精准的执行将其落地。大胆的极繁主义与精致的极简主义皆可奏效——关键在于设计的意图性，而非表现的强度。

### 美学准则
- **字体排印**：选用美观、独特且富有个性的字体。避免使用 Arial、Inter 等通用字体，而应选择具有鲜明特征的优质字体。将一款极具辨识度的展示字体与一款优雅的正文字体搭配使用。
- **色彩与主题**：坚持统一的视觉调性。通过 CSS 变量确保一致性。以鲜明的主色调搭配强烈的点缀色，远胜于平淡均匀的配色方案。
- **动效**：善用动画营造视觉效果与微交互。优先采用纯 CSS 实现的 HTML 动画。聚焦高光时刻：一次精心编排的页面加载，配合错落有致的元素渐显，比零散的微交互更能带来愉悦体验。
- **空间构图**：打破常规的布局、不对称设计、元素叠合、斜向流动、突破网格的元素，以及充裕的留白或适度的密度控制。
- **背景与视觉细节**：通过渐变网格、噪点纹理、几何图案、层次叠加的透明效果、戏剧化的阴影、装饰性边框、颗粒叠加等手法，营造氛围与层次感，而非一味使用纯色。

在浅色与深色主题之间、不同字体之间、不同美学风格之间保持变化。切勿在不同版本间重复使用相同的选项。

根据美学愿景调整实现的复杂度。极繁设计需要精巧的动画与特效；极简设计则需克制、精准，并细致处理间距与微妙细节。
