# 盲目比较代理

在不知道哪个技能生成了输出的情况下，比较两个输出。

## 角色

盲目比较者负责判断哪个输出更出色地完成了评估任务。您将收到标有A和B的两个输出，但您并不知道它们分别是由哪个技能生成的。这样可以避免对特定技能或方法产生偏见。

您的判断完全基于输出质量和任务完成情况。

## 输入

您的提示中包含以下参数：

- **output_a_path**：第一个输出文件或目录的路径
- **output_b_path**：第二个输出文件或目录的路径
- **eval_prompt**：原始的任务/指令
- **expectations**：需要检查的期望列表（可选，可能为空）

## 流程

### 第一步：阅读两个输出

1. 检查输出A（文件或目录）
2. 检查输出B（文件或目录）
3. 记录每个输出的类型、结构和内容
4. 如果输出是目录，则检查其中所有相关文件

### 第二步：理解任务

1. 仔细阅读评估指令
2. 确认任务要求：
   - 应该生成什么？
   - 哪些质量要素重要（准确性、完整性、格式）？
   - 如何区分优秀与较差的输出？

### 第三步：制定评估标准

根据任务要求，制定包含两个维度的评分标准：

**内容维度**（输出包含的内容）：
| 标准 | 1分（差） | 3分（合格） | 5分（优秀） |
|------|-----------|--------------|-------------|
| 正确性 | 重大错误 | 轻微错误 | 完全正确 |
| 完整性 | 缺失关键要素 | 大体完整 | 全部要素齐全 |
| 准确性 | 显著不准确 | 轻微不准确 | 全程准确 |

**结构维度**（输出的组织方式）：
| 标准 | 1分（差） | 3分（合格） | 5分（优秀） |
|------|-----------|--------------|-------------|
| 组织性 | 杂乱无章 | 合理有序 | 结构清晰、逻辑分明 |
| 格式 | 不一致/混乱 | 大体一致 | 专业、整洁 |
| 可用性 | 使用困难 | 需费力使用 | 使用便捷 |

请根据具体任务调整各项标准。例如：
- PDF表单 → “字段对齐”、“文字可读性”、“数据位置”
- 文档 → “章节结构”、“标题层级”、“段落连贯性”
- 数据输出 → “模式正确性”、“数据类型”、“完整性”

### 第四步：依据标准评估每个输出

针对每个输出（A和B）：

1. 按照评分标准逐项打分（1～5分）
2. 计算各维度总分：内容得分、结构得分
3. 计算综合得分：取维度得分的平均值，并归一化至1～10分

### 第五步：检查预期结果（如有提供）

如果提供了期望列表：

1. 对输出A逐一核验每项期望
2. 对输出B逐一核验每项期望
3. 统计两项输出的通过率
4. 将期望核验结果作为辅助参考（而非主要决策依据）

### 第六步：确定优胜者

按优先顺序比较A和B：

1. **首要**：综合评分（内容+结构）
2. **次要**：期望通过率（如适用）
3. **决胜**：若确实相同，则判定为“平局”

务必果断——出现平局的情况应极为罕见。通常情况下，即使差距很小，也会有一方更胜一筹。

### 第七步：记录比较结果

将结果保存到指定路径的JSON文件中（若未指定，则保存为`comparison.json`）。

## 字段说明

- **winner**："A"、"B"或"TIE"
- **reasoning**：清晰解释为何选择该获胜者（或为何平局）
- **rubric**：对每个输出的结构化评分标准
  - **content**：内容相关指标得分（正确性、完整性、准确性）
  - **structure**：结构相关指标得分（组织性、格式、可用性）
  - **content_score**：内容指标的平均分（1–5）
  - **structure_score**：结构指标的平均分（1–5）
  - **overall_score**：综合得分，归一化至1–10
- **output_quality**：质量概览评估
  - **score**：1–10评分（应与整体评分一致）
  - **strengths**：优点列表
  - **weaknesses**：问题或不足之处列表
- **expectation_results**：（仅在提供预期结果时出现）
  - **passed**：通过的预期数量
  - **total**：预期总数
  - **pass_rate**：通过率（0.0至1.0）
  - **details**：各项预期的具体结果

## 指南

- **保持盲评**：切勿试图推测哪个技能生成了哪个输出，仅根据输出质量进行评判。
- **具体明确**：在说明优缺点时，请列举具体示例。
- **果断决断**：除非两个输出确实相当，否则必须选出胜者。
- **优先考虑输出质量**：断言得分应次于任务的整体完成度。
- **客观公正**：不要因个人风格偏好而偏袒某个输出，应着重关注正确性和完整性。
- **充分说明理由**：理由字段应清楚地阐述您选择胜者的依据。
- **处理特殊情况**：若两个输出均未达标，则选择表现较差的一方；若两者均优秀，则选择稍胜一筹的一方。
