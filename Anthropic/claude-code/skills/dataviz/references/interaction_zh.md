# 交互——工具提示与筛选器

HTML 图表默认是可交互的——悬停层是交付内容的一部分，而非附加功能。省略它才是例外（比如仅显示一个统计数值的卡片），绝非默认行为。设计时应像对待静态渲染一样用心。

## 工具提示与悬停效果

工具提示**用于增强信息，绝不作为信息入口**：工具提示所展示的每一项数值，都可以通过直接标签或表格视图无需工具提示即可获取。键盘聚焦时显示的信息与悬停时一致。

- **十字准线锁定 X 轴位置。** 垂直的细线会跟随指针，并自动吸附到最近的数据点。读者瞄准的是日期，而不是一条 2px 的细线。
- **对于柱状图和单元格，标记本身即为点击/聚焦目标。** 不再使用十字准线；每个柱子、扇区、点或热力单元都自带 `pointermove`/`focus` 事件的工具提示，显示类别和数值，并且被悬停的标记会轻微变亮或加边框，让读者直观感受到响应。
- **单个工具提示覆盖所有系列。** 在该 X 轴位置，工具提示会列出所有系列的数据——指针无需落在某条线上或某个填充区域上才能获取数值。
- **标签是不可信数据，应使用 `textContent`。** 系列名和类别名通常来自 CSV 表头、工具输出或 API 响应。在将它们插入工具提示、图例或表格的 DOM 时，请使用 `textContent` 或 `createTextNode`，切勿通过 `innerHTML` 字符串拼接的方式。
- **数值优先，标签次之。** 在工具提示中，数值是强对比度的主体元素，而系列名称则为次要信息——与图例的层级顺序相反，因为此时读者已知系列，只想快速获取数值。
- **用线条标识系列，而非方块。** 工具提示中的每一行以一小段同色线条来标识对应的系列；在工具提示信息密集时，实心方块会占用过多视觉空间，徒增冗余。 （图例仍保持与标记一致：柱状图/面积图用矩形，折线图用线条。）
- **点击/聚焦区域大于标记本身。** 标记的悬停/聚焦区域不仅包括其 2px 的绘制范围，还应适当扩大——绝不能仅限于实际绘制的像素。8px 的散点难以精准命中；应为每个点设置至少 **24px** 的透明点击区域，或者在密集散点图中使用最近邻/沃罗诺伊层，使指针只需“最接近”即可触发，不必完全居中。（十字准线已在折线图和柱状图中实现了 X 轴的类似功能；散点图和气泡图则需要逐点版本。）
- **超出标记范围的数值会显示在工具提示中。** 当小柱子内部无法容纳标签时（参见 `marks-and-anatomy.md`），该柱子的点击区域会在悬停和聚焦时承载数值——工具提示成为其溢出的归宿，而表格视图则确保无需悬停也能随时查看。

## 筛选器与时间范围

每个监控仪表盘都需要相同的控件。这些是**标准的 UI 元素，而非图表标记**——使用普通的 HTML 表单控件构建，并将其样式与图表的整体风格相匹配。数据可视化仅补充以下组合规则：

- **统一置于图表上方的一行。** 筛选器应排列在内容上方的单一行中，左对齐——绝不在单个图表卡片内，也绝不同图表分别设置。如果某个图表需要独立的时间范围，则应单独设立一个仪表盘。
- **时间范围优先。** 这是所有用户都会首先使用的筛选条件；预设选项（今天、过去 7/30/90 天）应置于自定义范围之前。
- **筛选器作用于其下方的所有内容。** 每个图表、统计值和表格都会基于同一时间切片重新渲染，确保数据之间始终一致。
- **重载时保留框架。** 数据刷新期间，图表会以较低的透明度保留上一次的渲染结果——避免出现骨架屏、布局跳动或画面闪烁。

优秀的日期选择器应以列表形式展示预设选项（没有人会为了“过去 30 天”而去翻看日历网格），用 16px 的粗体勾选标记当前选择，悬停时仅显示淡淡的半透明高亮而不与选中状态冲突，并将自定义范围收起至页脚处的一条细线下方。（参考规格请见 `palette.md`。）
