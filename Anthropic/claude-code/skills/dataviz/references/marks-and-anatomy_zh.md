# 标记与构成

沉静而考究的视觉风格由若干固定规格的标记，以及两处留白构成。
唯有数据本身可以“喧闹”。

## 标记规格（在所有图表中保持一致）

| 标记 | 规格 |
|---|---|
| 柱/条形 | **厚度 ≤ 24px**（上限控制——绝不填满空间；让剩余部分留白）；**数据端点圆角 4px，基线处为直角**；均从同一条基线起始延伸 |
| 折线 | **2px 粗细**，圆角连接与端点 |
| 数据点/末端标记 | **≥ 8px**（半径 ≥ 4），填充为该系列的颜色 |
| 面积填充 | 该系列色相，**约 10% 透明度**（淡色铺底，绝非纯色实块） |
| 网格线/坐标轴 | 比表面色略浅的灰色，**极细（1px）、实线**（绝不虚线），处于次要地位 |

## 两处留白（以白色实现分隔）

- **表面间隙。** 表面色的 **2px 间隙** 用于分隔相互接触的标记——堆叠柱状图中的每个分段，以及相邻且宽度相同的柱形。在堆叠区域内保持统一的间隙宽度；通过间隙而非围绕它们绘制的边框，使相邻元素得以清晰区分。
- **表面环。** 数据点和末端标记带有 **2px 宽度的表面色环**，确保其在与折线交叉或相互重叠时仍具可读性。该环不仅是间距，也是标记的悬停/点击目标的一部分——参见 `interaction.md`（过小的数据点容易导致悬停区域过小）。

切勿为分隔标记而为其绘制边框。间隙与环才是分隔机制；额外的描边会增加非数据相关的墨量。

## 标签与图例

**当存在两个或更多系列时，必须配备图例**——这是可靠的身份标识渠道；切勿仅依赖颜色匹配来引导读者。直接标注则叠加于各标记之上，作为补充。**单个系列无需图例框**：因为只有一种颜色，图表的标题或副标题已说明所绘内容。带有一个色块的图例框只是对标题的重复，且占用空间。- **有选择地标注——绝不在每个数据点上都标数字。** 每个点或每段旁边都标注数值，只会让图表变得混乱且难以阅读。只需标注端点、极值，或故事所聚焦的那一条系列；其余数值则由坐标轴、图例和工具提示/表格来承载。直接标注之所以有效，恰恰在于其克制——一旦泛滥，反而失去作用。
- **先画标注再画网格线；先画网格线再加第二纵轴。**
- **无法完整显示的标签绝不截断——务必事先测量。** 只有当渲染后的文本在条形或堆叠段内两侧留有足够空白时，才将其放置于内部。若无法容纳：对于整条条形/柱形，将标签移至条形末端之外（或如外部无空间则移至工具提示）；对于堆叠段的“内部”部分（无自由端），则不使用内嵌标签，改由图例与工具提示来传递信息。无论哪种方式，数值都会保留在表格视图中，因此不会丢失任何数据。切勿通过设置 `overflow: hidden` 来“解决”这个问题——这会裁掉首尾字符，效果比完全不标注更差。文本绝不能溢出或被自身标记所截断。
- 条形图：数值标注在顶端。柱形图：数值标注在顶部封口处。折线图：数值标注在线段末端。
- 纵轴刻度：四舍五入为整数（0 / 1,000 / 2,000），并以千位分隔符格式显示；它们用于承载未直接标注的数值，除非所有数值均已标注，否则应保留。
- **文本绝不用数据色。** 标记（条形、折线、点、面积填充）采用系列颜色；而标签、数值、图例及坐标轴文本则使用**文本配色**（主色 / 次色 / 弱化色）。浅色分类色（黄色、青色）用作文本时难以辨认。视觉上的身份识别来自文本旁的彩色标记——一个点、一段简短的线键、一块色块——而非给文本本身着色。唯一例外是放置于彩色填充内部的标签（如堆叠段或地图区块）：应根据填充的明度选择白色或深色，以确保始终满足对比度要求。
- **末端标签发生重叠时，不要堆叠它们。** 直接标注末端在各系列在右端彼此分离时效果良好。但当多条线汇聚时，垂直方向上微调标签间距会使标签脱离所属线条，反而显得杂乱——此时应使用**引导线**（从标签指向线端的细线连接）、拆分为**小多图**，或退而求其次，依赖图例与工具提示。当汇聚的系列超过约4条时，通常更适合采用小多图布局。

## 数字型图表——当形式本身就是数字

- **统计卡片**规范：`标签`（句子大小写，末尾不加冒号）· `数值`（无衬线半粗体，自动紧凑：1,284 / 12.9K / $4.2M）· `变化量`（可选；带正负号，相对于指定时期；颜色依趋势方向及上升是否为好而定）· `趋势`（可选；12号微缩折线图，采用弱化色，当前时期用强调色）。
- **仪表盘：** 填充部分体现严重程度（强调色 → 警告色 → 危险色）；未填充的背景轨道则采用**同一色阶的较浅一级**（如蓝套蓝等），以便整体读取状态。
- **核心数字。** 仪表盘最突出的单一数值，字号≥48px，与页面其他文字采用同一种无衬线字体（绝不用展示型或衬线字体——那样会显得像非官方装饰）。每个视图仅保留一个。
- **大数值用比例字形；仅在列中使用等宽字形。** 较大的独立数值（核心数字、统计卡片中的数值）应使用字体默认的比例字形——启用 `tabular-nums` 会使每个数字宽度都等同于“0”，导致类似“121”这样的数字在较大尺寸下显得松散。仅在需要纵向对齐的数字列（表格行、坐标轴刻度）中使用 `font-variant-numeric: tabular-nums`。

## 纹理——备用通道（需主动启用）

在色彩失效的情况下——如重度色觉障碍、灰度打印或“强制色彩”模式——纹理承载着视觉辨识度。采用单向手绘填充，且仅以**45°及其135°镜像角度**使用（绝不使用水平或垂直方向——那样会被误认为网格线或条纹）。墨色采用同色系渐变（比填充本身的色阶再低一级），确保各区域的视觉响度一致。在明度刻度上，该纹理是*有序排列*的（旋转角度按幅度分级；线条倾斜角度承载正负符号），从而不会错误传达明度信息。此纹理由辅助功能设置、打印或“强制色彩”模式触发——默认情况下不启用。（参见 `palette.md`。）
