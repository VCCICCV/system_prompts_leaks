# 选择合适的图表形式

请在确定颜色之前先决定图表形式。数据的用途决定了该采用何种形式——有时，最合适的形式并非图表。

## 真的是需要图表吗？

| 数据类型 | 推荐使用 | 不推荐 |
|---|---|---|
| 单个当前值（+ 可能带趋势） | **指标卡片**（数值 + 变化量 + 微型折线图） | 单条柱状图 |
| 少量关键数值 | 指标卡片组成的 **KPI 行** | 分组柱状图 |
| 仪表盘中最突出的那个数字 | **主视觉数字**（≥48px，无衬线字体） | - |
| 单个相对于限制的比率 | **仪表盘**（同色系渐变刻度） | 两部分的饼图 |
| 超过约7类且每类都有明确含义 | **表格**（或表格+图表） | 更多颜色 |

如果确实需要图表，请根据数据用途选择图表类型：

## 用途 → 图表类型

| 用途（读者需完成的任务） | 默认形式 | 颜色处理 |
|---|---|---|
| 比较大小，从小到大 | 柱状/条形图；网格用 **热力图** | 顺序色系（单色相） |
| 时间序列趋势 | 折线图；单系列可用面积图 | 顺序色系或1种分类色 |
| 区分不同系列 | 分组/堆叠柱状图、多条折线 | **分类色系** |
| 一个系列是重点，其余为背景 | **强调式**（突出一个，其余灰色） | 1种色相+灰色 |
| 高于/低于基准线；与目标的偏差 | 分离型柱状图，或折线与基准线对比 | 分离色系 |
| 部分与整体的关系 | **堆叠柱状图**（类别多或名称长时可横置） | 分类色系 |
| 有序尺度占比（李克特量表、情感、同意↔反对） | **分离型堆叠柱状图**，以中性为中心 | 分离色系 |
| 每项的“前后”对比 | 杠铃图 | 1种色相，2种深浅 |

## 表格背后的规则

- **顺序色系是最安全的默认选择。** 单色相，深浅渐变。它保持易读性和一致性，不易误读。除非数据用途明确是“识别”或“极性”，否则优先选用。
- **分类色系适用于系列本身就是关注对象的情况**——但也有代价：可能掩盖真正重要的那一个数据点。如果故事是“这一项上升了”，那就用 **强调式**，而非分类色系。
- **强调式**是最被低估的表达方式。一个系列用强调色，其余用弱化色。往往是让图表更清晰的最直接方法。
- **纹理是一种可选的表达手段，而非默认形式。** 它仅在以下情况下才有意义：无障碍需求（完全色觉障碍）、打印/导出，以及 `forced-colors` 模式下。绝不能用于装饰。→ 参见 `marks-and-anatomy.md`。

## 系列数量阶梯（分类色系）

| 系列数 | 处理方式 |
|---|---|
| 1–3 | 单纯使用颜色对所有人友好；直接标注 |
| 4 | 相邻形式（堆叠、柱状、折线）仍安全，但必须直接标注——黄色和橙色开始共存屏幕；成对形式（散点图、气泡图、区域地图、小多图）上限为 **三**——超过则归入“其他”或分面，而非容纳第四个系列 |
| 5–6 | 弱上限；使用图例或小多图 |
| 7–8 | 临界点；超过则将尾部归入“其他”，或分面为小多图，亦可采用复合编码（色相×形状） |

切勿通过增加色相来解决“系列过多”的问题。生成的第九种色相在色觉障碍条件下与现有色相难以区分，并会破坏所有校验。
