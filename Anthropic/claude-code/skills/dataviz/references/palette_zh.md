# 参考调色板

这是数据可视化方法的**参考实例**：方法所需的所有参数均已使用经过验证的默认调色板填充。该技能的其余部分与具体系统无关——**要适配您的品牌，请替换此文件中的值**并重新运行验证程序，其他内容无需更改。

## 如何使用这些值

以下所有颜色均为纯十六进制格式。在 HTML 图表中，**将您使用的色槽定义为局部 `<style>` 块中的 CSS 自定义属性**置于文件顶部，然后在整个图表中按角色引用它们——这样，浅色/深色值只需在一个地方切换，而图表主体则基于角色而非原始十六进制值进行编写：

```css
.viz-root {
  color-scheme: light;
  --surface-1:      #fcfcfb;   /* 图表背景 */
  --text-primary:   #0b0b0b;
  --text-secondary: #52514e;
  --series-1:       #2a78d6;   /* 分类色槽 1 */
  /* ...仅列出本图表使用的角色 */
}
@media (prefers-color-scheme: dark) {
  :root:where(:not([data-theme="light"])) .viz-root {
    color-scheme: dark;
    --surface-1:      #1a1a19;
    --text-primary:   #ffffff;
    --text-secondary: #c3c2b7;
    --series-1:       #3987e5;
  }
}
:root[data-theme="dark"] .viz-root {
  color-scheme: dark;
  --surface-1:      #1a1a19;
  --text-primary:   #ffffff;
  --text-secondary: #c3c2b7;
  --series-1:       #3987e5;
}
```

如上所示，在两种作用域下均声明深色值：媒体查询覆盖操作系统设置；`data-theme` 作用域则覆盖查看者的主题切换，且两者必须同时生效（`:not(...)` 保护确保浅色优先于系统深色；`:where()` 使媒体块位于主题切换作用域之下）。

## 分类调色板

两种模式均已选定。深色列是为深色背景专门调整的八种色调，并非独立的调色板：

| 色槽 | 色相 | 浅色 | 深色 |
|------|------|------|------|
| 1 | 蓝色 | `#2a78d6` | `#3987e5` |
| 2 | 橙色 | `#eb6834` | `#d95926` |
| 3 | 青绿色 | `#1baf7a` | `#199e70` |
| 4 | 黄色 | `#eda100` | `#c98500` |
| 5 | 紫红色 | `#e87ba4` | `#d55181` |
| 6 | 绿色 | `#008300` | `#008300` |
| 7 | 紫色 | `#4a3aa7` | `#9085e9` |
| 8 | 红色 | `#e34948` | `#e66767` |

按照默认的“相邻”配对规则（堆叠图、柱状图、折线图），此顺序在两种模式下均能通过所有严格测试：最差相邻色盲 Delta E 为浅色 9.1、深色 8.4（OKLab ×100，目标 ≥8）；最差相邻正常视力 Delta E 为浅色 19.6、深色 19.3（底线 ≥15）。在“所有配对”模式下（散点图、气泡图、区域地图、小多图），全部八种颜色无法满足最低要求——当 28 种可能的配对全部存在时，任何排序都无法达标，且根据已记录调色板的规定，不得重新调整色阶。因此，这些图表类型需限制系列数量：**前三个色槽在两种模式下均能通过所有配对测试**（最差配对色盲 Delta E 为浅色 9.2、深色 9.4；正常视力 24.0 浅色 / 20.9 深色——均高于色盲警告阈值）。超过三个色槽时，应归入“其他”类别或进行分面处理：第四色槽会将黄色和橙色并列显示，而这组配对无法达到所有配对的最低标准（正常视力 13.7 浅色；色盲 4.8 深色）。浅色模式下的三种色槽（紫红色、黄色、青绿色）在浅色背景上的对比度低于 3:1，此时适用**缓解规则**（显示直接标签或表格视图）。深色色阶是针对深色区间（OKLCH L ~ 0.48–0.67，深色背景对比度 ≥3:1）选择并整体验证过的。（排序沿革：2026 年 7 月采用，因其开篇更和谐——与前代相同八种色相及色阶，仅调整了顺序，未更改任何十六进制值。前代仅前四个色槽通过了所有配对测试，其深色范围处于色盲警告带（6–8），因此需要辅助编码；而本排序则有意牺牲了第四个色槽——黄色现与橙色相邻——以获得更美观的前排色彩。若实际图表中出现四条及以上系列时，黄色与橙色混淆的情况，则可重新评估这一权衡；恢复原序只需简单调整顺序即可。）当您替换为自有色阶时，请确保您的调色板符合全部测试要求。槽位**排序**是CVD安全机制，而非外观设计——候选排序被逐一枚举，只有在两种模式下都能通过所有相邻门限的排序才会被保留（参见`color-formula.md` § 主题）；这一默认排序是众多通过排序之一，因其起始色彩而被选中。当你替换成自家品牌的色相时，也请同样操作：对候选排序运行验证器，仅从通过的排序中进行选择。

## 顺序色相

默认单色相：**蓝色**，由浅至深。当两个连续上下文同时出现时，第二个会采用下一个分类槽位的色相（橙色），各自形成独立的单色相渐变。

| 步骤 | 十六进制 | 步骤 | 十六进制 | 步骤 | 十六进制 | 步骤 | 十六进制 |
|---|---|---|---|---|---|---|---|
| 100 | `#cde2fb` | 250 | `#86b6ef` | 400 | `#3987e5` | 550 | `#1c5cab` |
| 150 | `#b7d3f6` | 300 | `#6da7ec` | 450 | `#2a78d6` | 600 | `#184f95` |
| 200 | `#9ec5f4` | 350 | `#5598e7` | 500 | `#256abf` | 650 | `#104281` |
| | | | | | | 700 | `#0d366b` |

完整的100→700范围用于**顺序**编码（连续量值——热力图、区域地图），其中最浅的步骤表示“接近零”，并允许其色调逐渐淡出至背景。对于**序数**渐变（离散有序标记——漏斗各阶段、层级——使用`--ordinal`验证），靠近背景的步骤仍需满足2:1对比度要求：浅色端不得浅于**第250步**（`#86b6ef`，2.06:1）；深色端不得深于**第600步**（`#184f95`，2.15:1）。

## 分离型配对

**蓝↔红**——冷暖两极，读作对立。中性中间点为灰色（浅`#f0efec`，深`#383835`）。两侧步数相等。（蓝↔青方案被否决——两者均为冷色，中间点无法表达“无”之意。）

## 状态色板（固定，永不主题化）

| 角色 | 十六进制 | 浅色背景对比度 | 深色背景对比度 |
|---|---|---|---|
| 良好 | `#0ca30c` | 3.27 | 5.19 |
| 警告 | `#fab219` | 1.79 | 9.49 |
| 严重 | `#ec835a` | 2.57 | 6.60 |
| 临界 | `#d03b3b` | 4.68 | 3.62 |

深色：同样四步——在深色背景（`#1a1a19`）上均满足3:1对比度，并与深色分类槽位保持区分。在浅色背景下，警告与严重本就低于3:1；通过**图标+标签**的组合来弥补，因此状态色从不单独承载含义。这些步骤刻意与分类槽位区分开来，以免状态色冒充系列色——区分足够明显，一眼即可分辨，但又不足以仅靠色相完全区分：以系列底色条测量（未模拟的Delta E≥15），每种模式下约有九组分类色与状态色之间的差异低于15——在浅色模式下，红色与临界、黄色与警告的差异均为4.8，第2号橙色与严重状态的差异为5.8，而浅色成功文本绿`#006300`与系列绿色的差异为10.1；绿色与良好状态（9.7）在两种模式下均成立，因为这两个色号都与模式无关。总体规则是：任何系列色若与同色系的状态或差异提示并列，均依赖于图标+标签的组合以及位置安排，绝不能仅凭色相来区分。

## 纹理填充（辅助功能通道）

一种手绘**“线条”**填充，仅以**45°及其135°镜像**使用。墨色为同色系（填充自身渐变中的较深一步）。在数值尺度上，它是*有序*的（旋转角度随量值变化；臂角承载分离符号）。由辅助功能设置、打印或`forced-colors`触发——绝不用于装饰，且默认不启用。

## 筛选控件

筛选器属于标准的界面组件，而非图表组件——图表层仅在 `interaction.md` 中定义了交互规则。日期范围控件由一组预设选项（今日、过去7/30/90天、本月至今）组成，通过16px粗体勾选标记当前选中项，悬停时显示半透明背景，底部则以细线分隔自定义范围。维度筛选器为标准的下拉列表。

## 字体与数字样式

所有文字——包括主视觉数字——均采用系统默认无衬线字体：`system-ui, -apple-system, "Segoe UI", sans-serif`。任何地方都不使用装饰性或衬线字体。较大的独立数字（主视觉数字、统计卡片数值）使用默认的比例数字；对于需要垂直对齐的列（表格行、坐标轴刻度），则使用 `font-variant-numeric: tabular-nums` 来设置等宽数字。请在此处替换为您品牌的UI无衬线字体。
