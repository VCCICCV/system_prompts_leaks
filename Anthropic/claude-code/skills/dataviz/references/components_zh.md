# 组件——构成图表的各个部分

图表由这些部件组成，以纯 HTML/SVG 的形式组装而成。第 0 层是所有元素的基座；系统层则使方法具备可移植性（而这一层本身也构成了这项技能）。

## 第 0 层——基础
- **颜色角色**：分类色系（8 种明/暗）、顺序渐变、发散色对、状态色（4 种）、弱化色/“其他”色，以及灰度图表装饰元素（坐标轴/网格/标签/表面）。这些颜色均在 HTML 的顶部以 CSS 自定义属性的形式定义——参见 `palette.md`。
- **纹理填充**：方向性填充及 45°/135° 旋转。
- **图表容器**：一个 `<figure>` 元素（或卡片式 `<div>`），负责响应式尺寸调整、标题/说明文字，以及**表格视图切换控件**（每个图表的辅助功能孪生组件）。**任何固定高度都应包含 x 轴区域**（绘图区高度 + 轴标签高度），以避免卡片内部出现嵌套的垂直滚动条；建议让容器随内容自适应扩展。
- **图例**（支持隔离切换、识别纹理的色块）· **工具提示** · **坐标轴** · **数据标签**。

## 第 1 层——用户常要求的图表类型
- **柱状图**：分组与堆叠，薄柱为默认样式，支持横向与纵向布局。
- **折线图**：多系列，带柔和填充的面积变体，并配备辅助功能标记。
- **统计信息卡**：显示数值、变化量，可选配微型折线图（作为图形的基本规范）。
- **仪表盘/进度条**：采用统一的渐变色带。

## 第 2 层——完善组件集
- **面积图**（堆叠型，带边线）· **微型折线图** · **热力图**
- **比例图例**（顺序型/发散型）· **图表筛选器/时间范围选择器** · **空状态提示**

## 系统层——成为核心技能
- **六项校验器**：`scripts/validate_palette.js`（用于调色板验证）。
- **主题引擎**：将客户提供的色阶自动调整至合规值（参见 color-formula.md）。
- **图表类型启发式算法**：根据数据特征选择合适的图表形式（参见 choosing-a-form.md）。
- **表格视图生成器**：为任意图表提供符合 WCAG 标准的等效表格视图。

备注：部分与整体的关系基于堆叠柱状图；环形图仍处于较低优先级。小多图是一种基于上述图表的布局模式，而非独立的组件。若数据密集分布于散点图上，则将其归入第 2 层。
