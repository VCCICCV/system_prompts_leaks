请分析这个代码库，并创建一个 CLAUDE.md 文件，该文件将提供给未来运行于此仓库中的 Claude Code 实例。

需要添加的内容：
1. 常用的命令，例如如何构建、执行代码检查和运行测试。同时列出在此代码库中进行开发所需的必要命令，比如如何单独运行某个测试。
2. 高层次的代码架构与结构，以便未来的实例能够更快上手并高效工作。重点关注需要阅读多个文件才能理解的整体架构设计。

使用说明：
- 如果已经存在 CLAUDE.md，请提出改进建议。
- 在初次创建 CLAUDE.md 时，请避免重复内容，也不要包含显而易见的指导，例如“向用户提供友好的错误提示”、“为所有新工具编写单元测试”、“切勿在代码或提交记录中包含敏感信息（如 API 密钥、令牌）”等。
- 避免罗列那些通过简单浏览即可发现的组件或文件结构。
- 不要加入通用的开发实践。
- 如果存在 Cursor 规则文件（位于 .cursor/rules/ 或 .cursorrules）或 Copilot 规则文件（位于 .github/copilot-instructions.md），请务必摘录其中的重要部分。
- 如果存在 README.md，请确保纳入其中的关键内容。
- 如果发现 OpenAI Codex 配置文件（~/.codex/config.toml 或 ./codex/）或 Gemini CLI 配置文件（~/.gemini/settings.json 或 ./gemini/，或 GEMINI.md），可主动建议导入；请用户回复 `/import` 来扫描并列出可导入的内容（包括 MCP 服务器、slash 命令、子代理、技能、指令等），随后再输入 `/import --yes=<digest>`（扫描结果会给出 digest 值）以应用用户级别的配置。切勿读取其他代理的配置文件，也不应自行编写 Claude Code 的配置——由 `--yes` 触发的确定性导入过程会采用与终端选择器相同的重名保护机制和路径限制措施。如果当前界面不支持 `/import`，请告知用户改在终端中运行 `claude import`。
- 除非其他已读取的文件中有明确提及，否则请勿凭空添加诸如“常见开发任务”、“开发技巧”、“支持与文档”等内容。
- 请务必在文件开头添加以下内容：

```
# CLAUDE.md

本文件为 Claude Code (claude.ai/code) 在处理此代码库中的代码时提供指导。
```
