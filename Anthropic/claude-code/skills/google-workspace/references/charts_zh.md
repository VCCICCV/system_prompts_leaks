# 图表

请先阅读 `references/slides.md` 中的幻灯片设计规范；本文件专门介绍幻灯片中的图表。假设每张图表都会被投影、打印或转发，而讲解者不在现场，因此读者所需的一切信息都应直接体现在图表中。

## 选择合适的图表类型

| 读者需要… | 推荐使用 |
| :---- | :---- |
| 查看一两个数值 | 不用图表：用项目符号列出文字，或以大号字体显示数值（如“15%”），并在下方用较小字号注明其含义（如“上季度营收增长率”）。这比单条柱状图或双扇形饼图更清晰 |
| 比较各分类间的量级 | 柱状图：默认为竖向柱，当分类名称较长时可使用横向柱 |
| 展示趋势，或需要将数据点连接起来的情况 | 折线图：适用于时间序列及其他连续数据，但不用于分类数据；当平均值与波动范围同等重要时，可添加误差线或阴影区域 |
| 观察少数项目在两个时间点之间的变化 | 斜率图（无网格线和数值轴），例如按地区划分的教育水平，2015年对比2025年，而非多系列柱状图。线条不宜过多，用强调色标示变化最大的那一条；左侧仅标注起始值，右侧同时标注终点值和名称 |
| 突出某一条数据系列并将其置于背景中 | 将该系列用强调色绘制，其余部分设为灰色 |
| 展示整体中各部分的占比 | 堆叠柱状图：绝对值堆叠用于比较总量及其构成，百分比堆叠用于比较结构比例。堆叠图表容易显得杂乱，适合展示总体趋势，而不宜用于精确比较中间部分 |
| 比较各分类间有序等级的数据（如李克特量表） | 百分比堆叠的横向柱状图：确保最左端和最右端有统一的基准线 |
| 跟踪起点、变化过程及最终结果 | 漏斗图：将复杂的计算过程分解为若干步骤 |
| 同时观察二维数据（如细分大小及其内部构成） | Mekko图 |
| 展示时间进度安排 | 甘特图 |
| 反映两个变量之间的关系 | 散点图：主要用于样本分析和研究；在商业场景中，若确实存在明确的关联，则也可使用 |
| 表示常规图表难以呈现的数据 | 使用图形化示意：漏斗、方格、示意性柱状图等，适用于数据不适合常规图表且无需精确单位的情况，但需明确标注并非等比例 |

- 避免使用以下图表，除非用户特别要求：饼图和甜甜圈图（人对角度的判断往往不准，建议改用排序后的柱状图）；面积图（不易读，唯一例外是正方形面积图，其中每个正方形的面积代表一个数值，适用于规模差异极大的数据，如TAM、SAM和SOM）；三维图表；以及次坐标轴（两条刻度的对齐纯属人为，会虚构相关性；应分别标注每条线的单位，或将两组数据叠加在同一水平轴上，或以共同基准对两组数据进行指数化处理）。
- 一到三条彩色系列易于辨识；四条及以上时，即使幻灯片已使用图例，也应直接在每条系列旁标注名称；一张图表最多容纳五到六条系列。超过此数量时，可将最小的部分合并为“其他”，或采用小倍数图（在共享刻度下排列一组小型、样式相同的图表）。切勿通过增加颜色来解决“系列过多”的问题。
- 在某些情况下，组合图表是合理的，例如在图表、小表格或文本框中，将堆叠柱状图中的一条细分单独拆分出来，以便观众获取该细节信息。

## 图表遵循的标准

如果演示文稿中已有图表，并且它们在风格上保持一致（如坐标轴处理、网格线、图例或直接标注、标签位置、标题位于图表内还是上方、字体、颜色等），则以此为标准，所有新图表均应遵照执行，即便与主主题有所差异。相互矛盾的图表不能视为统一标准。否则，请遵循以下通用标准。

在牌组标准下，牌组的图表样式决定了所有由公司标准所规定的内容，包括标题的位置及其表述方式。如果无法直接复制其样式，可复制牌组中的某一张图表，并替换其中的数据和标签，这是获得完全一致外观的最稳妥方法。

## 公司标准

- **无图例**，除非“收尾工作”中允许使用系列名称作为图例。
- **条形图和柱状图：** 不显示网格线，不显示数值轴；每个条形或柱体上均标注其数值，类别轴用于标识各条形或柱体。保留一条细灰色的类别轴线（约#BFBFBF），以避免条形或柱体显得悬浮。
- **折线图：** 在四到五个整数刻度处绘制浅色水平网格线，便于读者读取数据值（浅色指接近背景色：白色背景时为浅灰色，深色背景时为略低于黑色的深灰色）；数值轴标签采用柔和的颜色并标明单位（如“$0B”、“$25B”），且不显示轴线；不显示垂直网格线。仅在已标注的点上设置小标记，其余点不设标记，以免过多标记使长折线显得杂乱。折线应以直线连接各点，不得平滑处理。
- **散点图：** 不显示网格线；两个数值轴均设置四至五个整数刻度，刻度标签采用柔和颜色的纯数字。
- **一种强调色** 用于传达核心信息的点，其余部分统一使用灰色。优先选用牌组的强调色：即主题的第一种强调色、牌组成品幻灯片所使用的强调色，或您在新建牌组时选定的强调色。仅当牌组本身没有明确的强调色时（默认主题，且无成品幻灯片使用强调色）才使用以下备选配色方案：强调色#1A6BB8，条形#BFBFBF，折线#A6A6A6，正文#1A1A1A，辅助文本#595959。
- **透明背景。** 图表区和绘图区均无填充色和边框，使图表直接置于幻灯片背景之上。
- **数字格式中包含单位。** 每个条形或柱体上的数据标签均带有单位（如“$42M”、“38%”、“12K”）；只有单纯的计数（如355）可不带单位。对于堆叠柱状图，仅柱体总计带有单位（如“$40.5M”），各分段为纯数字（18.2、12.5、9.8），总计位于每个堆叠的顶部。
- **条形比例。** 条形之间的间距为条形宽度的50%，因此条形的宽度是间隙的两倍。对于堆叠条形，将系列重叠度设为100%，使各分段在同一条形上堆叠。
- **预留空间。** 将数值轴的最大值设定为最高条形高度的约15%以上，以便条形上方的标签能够完整显示；若条形上方有总计或增长箭头，则最大值应高出约25%。
- **排序。** 水平条形按数值从大到小排列，最大的位于顶部。
- **李克特量表及其他有序量表** 使用单一强调色的不同明暗渐变，量表顶端（如“非常同意”）最深，底端最浅，绝不采用红—绿渐变。此规则优先于“收尾工作”中关于基准线上下数值的双色调规则。
- **瀑布图：** 起始值和最终值为深灰色，增长部分使用强调色，下降部分使用一种对比鲜明的暖色，例如橙色#E07B39。每一步均标注其带符号的变化值，且总计带有单位。
- **文本。** 轴标签和数据标签采用牌组正文字体，字号为14pt；年份行和标注则使用较小字号（见“收尾工作”）。以系列颜色显示的文本（如折线名称、标注）在该系列为浅灰色时，改用辅助文本颜色。

## 图表标签

故事内容应体现在幻灯片标题中（或在牌组使用标签标题时体现在幻灯片说明中），而不在图表中。故事标题应以完整句子形式呈现核心结论及相应数值（如“销售额连续两个季度持续增长，2025年达到12.4百万美元”）。图表仅需附带描述性标签，标签内容按以下顺序用逗号分隔：所绘制的内容、如有范围则注明范围、单位、时间范围。- 单位应使用简写，不得完整拼写。货币单位的缩写遵循图表所在语言的惯例；若无明确语言，则采用默认规则：美式英语为$K、$M、$B（当语言不明确时亦以此为默认）；英式英语为£k、£m、£bn，依此类推。同一图表内不得混用不同单位约定。
- 括号内仅放置第二单位或数据基础，不得用于主单位。
- 图表中已呈现的内容始终保持不变。
- 当坐标轴显示年份时（如刻度标签“FY22”或年份行），可省略时间范围；当坐标轴仅显示具体时段（如“Q1”、“Jan”）时，则保留时间范围，例如在单年图表中，需在幻灯片的某处标注年份。
- 条形图和柱状图的每个数据标签以及折线图的价值轴标签均包含单位，因此图表标题中无需重复单位。堆叠柱状图的总计值会携带单位。散点图的坐标轴显示纯数字，故单位保留在图表标题中。
- 在制作首张图表时即确定本图表集各标题所包含的要素（范围、单位、时间），并在后续每张图表中统一应用这一规则及省略原则，每次新增图表前务必核对已有标题。若一半图表标注“$M, FY25”，另一半未标注，则显得不够严谨。
- 标题中不得出现以下内容：核心结论、具体数值（增长率、总量或变化应置于幻灯片标题、数据标签、增长箭头或标注框中）、各要素间的冒号或破折号、完整拼写的单位。

示例：

- 柱状图，条形标注“$42M”，横轴为“Q1 … Q4 | Q1 … Q4”，并有年份行标注“2024”和“2025” → **“季度收入”**，而非“季度收入，$M，Q1 2024–Q4 2025”。
- 柱状图，条形标注“$42M”，横轴为“Q1 … Q4”（单一年度，无年份行）→ **“季度收入，FY25”**：因横轴未显示年份，时间范围仍需保留。
- 折线图，纵轴标签为“0K … 250K”，横轴为“Jan … Dec | Jan … Jun”，并有年份行标注“2025”和“2026” → **“月活跃用户数”**：纵轴承载单位，年份行承载时间范围。
- 带增长箭头的柱状图，条形标注“$42M”，增长标签为“+21%” → **“季度收入，FY25（环比增长率）”**：第二单位以括号形式置于末尾。
- 分段占比条形图，条形标注“58%” → **“区域收入占比，FY25（基于报告的细分）”**：数据基础以括号形式注明。

图表标题为位于图表正上方、采用幻灯片标题样式文本框，其排版与幻灯片整体风格一致；图表自带的内置标题则不予显示。标题首字符应与幻灯片标题左对齐，保持相同的左侧位置及内部缩进（padding）。标题占位符通常带有非零缩进，而新建文本框的缩进为0.1英寸（7.2磅），因此应复制标题的缩进值，而非设为零。主题较短时，标题宜控制在一行；若主题较长（约六个单词及以上，如“按部门划分的季度销售额，产品X”），则将单位和时间范围置于次行，字号略小且颜色稍淡（如“FY25”或“$M, FY25”，视标题是否保留单位而定），避免标题换行或侵占图表区域。含两张及以上图表的幻灯片，每张图表应配有独立的描述性标题，而幻灯片标题则概括这些图表共同传达的信息。

## 图表布局

- 独立图表应占据整个内容区：从标题左侧边缘到右侧边缘，高度自标题下方至脚注上方。常见错误是图表高度不足，而非过大。
- 小多图布局：任一子图高度不应低于约120磅，否则标签无处安放。仅当比较目标为量级大小时，方可共享尺度；若共享尺度导致较小子图趋于扁平化，则应为每个子图单独设置尺度，并在标题中予以说明。

## 最终调整

图表制作完成后，应进一步调整，确保信息清晰可见：

- **每张图表只用一种颜色传达一个信息。** 第二种强调色就等于传递了第二个信息；如果有两个要点，就做两张图表。只有在需要明确区分不同系列时才使用不同的色调，并且在整个演示文稿中，同一实体在所有图表上都应采用相同的色调。用同一色调由浅至深来表示大小差异，用两种相对的灰色系颜色来区分高于或低于基准线的部分。切勿使用彩虹色系，也绝不能仅靠颜色来区分信息（尤其是红色和绿色）：必须辅以标签或位置说明。
- **数据来源标注** 放在图表下方，采用脚注字号（10–12pt，颜色较淡），置于 `references/slides.md` 中“脚注与来源”之后，且仅引用您实际使用的资料。
- **时间轴。** 刻度标签仅显示短周期（如 Q1…Q4、Jan…Dec）。年份位于每年第一个周期下方的第二行，字号为 11pt，采用辅助文字颜色，其余刻度不再重复标注；避免出现“Q1 FY25, Q2 FY25, …”等全周期标注。链接的 Sheets 图表尚无可靠方法实现这种标注，因此可在坐标轴下方添加小文本框。单年图表无需年份行，直接在标题中注明年份。
- **系列名称。** 为每条折线赋予简短名称，一到两个词（如“数据中心”），采用该系列的颜色，置于其最后一个数据点右侧，与数值对齐（如“$89.0B 数据中心”），并在图表右侧留出适当空白。除斜率图外，三条及以下折线的图表有两种例外：若整个演示文稿统一使用图例，则沿用图例；否则，当名称超过约 14 个字符时，改用小型图例而非换行的末端标签。四条及以上折线或斜率图则应直接缩写长名称。凡含两条及以上折线的图表，必须通过末端标签或图例为每条线命名，方可视为完成。
- **折线上标注点：** 标注起点、终点，以及标题或要点所提及的峰值、谷值或转折点。一条十点折线上标注三个点较为合适；超过四个则显得拥挤，而过长的折线仅标注首尾两点又过于简略。除末端标签外，其他标注均位于对应数据点的上方或下方，且不与折线重叠。
- **结论性标注：** 在下行区间加设阴影带，或在“下方注释”要求时添加标注说明。当实际数据转为预测时，应清晰标示分界线，以免将预测误读为历史：折线图中，预测部分用虚线表示；柱状图中，预测柱采用斜线填充或明显较浅的填充，其类别标签后加 E 后缀（如“2026E”、“Q3E”）。在分界处添加简短标注（“实际”|“预测”），有助于独立阅读该图表时的理解。
- **增长箭头：** 仅在变化显著时标注增长或下降，而非每对柱之间都标注。默认样式为折线箭头：从一根柱向上延伸，跨越其间柱体及其标签的高度，再向下指向另一根柱。直线箭头仅适用于相邻且上方留有空间的柱体之间。第三种形式是差值标记：在每个柱顶画一小横线，并在两水平间画一竖线，标注变化量。无论何种形状，变化数值均居箭头中央（折线箭头时位于其水平段），置于箭头前方，背景色与幻灯片底色一致。增长箭头和 CAGR 括号均为叠加于图表之上的图形元素，而非图表本身；应根据图表的几何布局进行定位。
- **注释说明：** 当幻灯片标题或解说提到趋势变化（加速、转折、启动、一次性事件）时，应在相应发生点添加注释，直接标注在图表上，而非仅在您的回应中提及原因。若您收到的材料中未指明原因，请询问或干脆不加注释，切勿自行猜测。大多数图表无需注释，最多一个，偶尔两个；超过此数量则会显得杂乱，相关解释宜放在图表旁的文字区块中。注释应为短语（如“供应链中断”、“产品 X 上市”），而非完整句子，字号 11–12pt，颜色与所标注系列一致，不加方框、边框或背景填充，并以同色细线从文字引向对应数据点。文字应放置在图表区域内最近的空白处，切勿覆盖柱体、折线或数据标签。
