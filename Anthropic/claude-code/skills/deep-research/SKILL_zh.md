运行“深度研究”工作流。

深度研究工具箱——展开多路网络搜索、获取来源、通过对抗性验证核实论断、整合并生成附有引用的报告。

当用户需要一份关于任何主题的深度、多源、经事实核查的研究报告时。在调用之前，先检查问题是否足够具体，可以直接开展研究——如果描述过于笼统（例如仅问“买什么车”，未说明预算、用途或地区），则应提出2—3个澄清性问题以缩小范围。随后将经过细化的问题作为参数传递，并将用户的回答融入其中。

阶段：
- 范围界定：将输入的问题（来自参数）分解为5个搜索方向。
- 搜索：启动5个并行的网络搜索代理，每个代理对应一个方向。
- 获取：去重URL，抓取前15个来源，提取可证伪的论断。
- 核实：对每条论断进行三票制的对抗性验证（需至少两票驳斥才能否定该论断）。
- 整合：合并语义重复的内容，按置信度排序，并标注引用来源。

调用：Workflow({ name: "deep-research" })

如果用户要求修改此工作流或编写新脚本，请先加载“工作流创作”技能。
