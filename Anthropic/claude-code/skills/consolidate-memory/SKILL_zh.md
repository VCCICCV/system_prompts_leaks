# 记忆整合

你正在对已掌握的关于该用户及其工作的信息进行一次反思性梳理。目标是：在下一次会话中，系统能够快速了解——他们与谁协作、关注什么、偏好怎样的工作方式——而无需再次询问。

你的系统提示中的自动记忆部分已定义了目录结构、文件格式和记忆类型，请遵照执行。

## 第一阶段 — 清点现状

- 列出记忆目录并阅读索引文件（`MEMORY.md`）
- 快速浏览每个主题文件，记录哪些内容存在重叠、哪些显得过时、哪些内容过于简略。

## 第二阶段 — 整合

**区分持久性与时效性。** 用户的偏好、工作风格、关键关系以及常用的工作流程属于持久性信息，应予以保留并进一步完善。而具体项目、截止日期及一次性任务则属时效性信息——若相关时间已过或工作已完成，可将该文件归档，或将其中的长期价值（如“用户偏好使用X格式撰写发布文档”）提炼并融入到持久性记忆中。

**合并重复内容。** 若两个文件描述的是同一个人、同一个项目或同一项偏好，则将其合并为一个，并保留内容更丰富的文件路径。

**修正时间表述。** 将“下周”、“本季度”、“周五前”等相对时间转换为绝对日期，以便日后仍能清晰查阅。

**舍弃易于重新获取的内容。** 如果某条记忆仅是对用户日历、文档或关联工具中现有信息的简单复述，则可删除。保留那些难以重新推导的信息：明确表达的偏好、决策背后的背景信息、以及遇到特定问题时该联系谁。

## 第三阶段 — 整理索引

更新 `MEMORY.md`，使其保持在200行以内、约25KB大小。每条记录占一行，长度不超过150字符：`- [标题](file.md) — 一句话摘要`。

- 删除指向已归档记忆的链接
- 缩短任何包含应置于主题文件中的详细信息的条目
- 新增任何新增的重要内容

最后附上简要总结：说明共处理了多少个文件以及发生了哪些变化。
