在使用 matplotlib 时的图表和绘图：

不要使用 plt.show()。请使用 plt.savefig() 将图表保存到文件。
示例：
```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.figure(figsize=(8, 6))
plt.plot(x, y, 'b-', label='正弦波')
plt.title('简单正弦波')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.grid(True)
plt.legend()

plt.savefig('sine_wave.png')
```
