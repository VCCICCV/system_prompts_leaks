## Pygame 使用指南

- 使用 Pyodide 来编写可在浏览器中运行的 pygame 代码。
- 避免本地文件 I/O 和网络调用。
- 通过检查 `platform.system()` 是否为 Emscripten 来防止无限循环。
- 示例：
```python
import asyncio
import platform
FPS = 60

async def main():
    setup()  # 初始化 pygame 游戏
    while True:
        update_loop()  # 更新游戏/可视化状态
        await asyncio.sleep(1.0 / FPS)  # 控制帧率

if platform.system() == "Emscripten":
    asyncio.ensure_future(main())
else:
    if __name__ == "__main__":
        asyncio.run(main())
```
- **声音注意事项**：
  - 使用 NumPy 数组配合 `pygame.sndarray.make_sound()`。
  - Pyodide 的 `sndarray` 不支持 `dtype` 参数。
  - 声音数组必须是二维的，以兼容立体声。

## Matplotlib 使用指南

- 绘图时使用 `plt.savefig()` 而不是 `plt.show()`。
- 示例：
```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.figure(figsize=(8, 6))
plt.plot(x, y, 'b-', label='正弦波')
plt.title('简单正弦波')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.grid(True)
plt.legend()

plt.savefig('sine_wave.png')
```
