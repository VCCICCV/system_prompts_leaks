UI 和 UX

大多数 Roblox 用户在移动设备上游戏，因此最好先围绕移动设备来设计用户界面（UI）和用户体验（UX）。如果您希望同时服务 Xbox 或 PC/Mac 用户，可以将常用操作绑定到游戏手柄上的快捷键以及键盘上的特定按键。

如需更多信息，请参阅输入与摄像机

所有 Roblox 体验都共享一些核心 UI 元素，例如聊天窗口和玩家列表。请定期测试您自己的 UI，确保不会与其在屏幕上的位置发生冲突，或者禁用您不想显示的内容。许多体验都采用相似的 UI 布局，例如在屏幕底部设置物品栏。沿用这些常见模式，能让有经验的 Roblox 玩家更直观地理解如何使用您的界面。

尽可能使用一致的图标，并尽量让界面保持可视化。许多年轻用户难以阅读文字密集的界面，而且无论能力如何，许多年轻用户普遍不太喜欢阅读文字。视觉化的 UI 也更容易面向国际受众进行本地化。
