    # AI SDK 概述

    AI SDK 是一个 TypeScript 工具包，旨在简化使用 React、Next.js、Vue、Svelte 和 Node.js 等多种框架构建 AI 驱动应用的过程。它为不同 AI 模型提供统一的 API，使将 AI 功能集成到您的应用中变得更加容易。

    AI SDK 的关键组件包括：

    1. **AI SDK 核心**：提供一种标准化方式，用于通过大型语言模型（LLM）生成文本、结构化对象和工具调用。
    2. **AI SDK UI**：提供与框架无关的钩子，用于构建聊天和生成式用户界面。

    ---

    ## API 设计

    AI SDK 提供了若干核心功能和集成：

    - `streamText`：这是 AI SDK 核心的一部分，用于从 LLM 流式传输文本。它非常适合交互式场景，如聊天机器人或需要即时响应的实时应用。
    - `generateText`：这也是 AI SDK 核心的一部分，用于根据给定的提示和模型生成文本。适用于非交互式场景，或在撰写电子邮件、总结网页等内容时使用。
    - `@ai-sdk/openai`：这是一个与 OpenAI 模型集成的包，允许您通过标准化的 AI SDK 接口使用 OpenAI 的模型。

    ### 核心功能

    #### 1. `generateText`

    - **用途**：根据给定的提示和模型生成文本。
    - **适用场景**：非交互式文本生成，例如撰写邮件或内容摘要。

    **签名**：
    \`\`\`typescript
    function generateText(options: {
    model: AIModel;
    prompt: string;
    system?: string;
    }): Promise<{ text: string; finishReason: string; usage: Usage }>
    \`\`\`

    #### 2. `streamText`    - **用途**：从给定的提示和模型中流式传输文本。
    - **用例**：聊天机器人或实时内容生成等交互式应用。

    **签名**：
    \`\`\`typescript
    function streamText(options: {
    model: AIModel;
    prompt: string;
    system?: string;
    onChunk?: (chunk: Chunk) => void;
    onFinish?: (result: StreamResult) => void;
    }): StreamResult
    \`\`\`

    ### OpenAI 集成

    `@ai-sdk/openai` 包提供了与 OpenAI 模型的集成：

    \`\`\`typescript
    import { openai } from '@ai-sdk/openai'

    const model = openai('gpt-4o')
    \`\`\`

    ### 1. 基本文本生成
