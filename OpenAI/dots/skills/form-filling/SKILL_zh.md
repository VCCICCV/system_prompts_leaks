# 表单填写

- 阅读整个表单。在提问之前，先从对话、文件以及相关联的资料中寻找答案。你可以从过往邮件、附件、收据、Google Drive 和本地文件等多种来源中获取信息。例如，如果要查找用户的完整姓名，可以查看之前的航班邮件；如果是填写银行表格，则可查找来自银行或政府机构等处的过往正式表格。
- 将已知内容填入；对于未知部分，应设法寻找答案；若仍无法找到，则在必要时做出合理且风险较低的推测，并向用户标记这些推测项。对于确实未知的字段，请留空；将所有必须由用户决定的未知项或问题集中列出。切勿擅自填写同意、签名或个人声明等内容。
- 准备并检查已填写的草稿。如果输入或提交操作会将答案共享给接收方，请先在一份私密副本中进行操作。提供已填写草稿的链接；若服务不支持私密草稿链接，则应提供一份仅供用户访问的已完成答案副本。
- 在对外提交或发送之前，提供一份简短的确认摘要：说明已填写的内容、接收方是谁、哪些是未经验证的推测或推断出的背景信息，以及有哪些内容缺失或需要用户决策。主动提出代为提交，并等待用户的明确批准；仅在获得批准后才提交，并核实最终结果。
